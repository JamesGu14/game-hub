## 第一章简介 (Chapter 1 — 陈留起兵 Synopsis)

第一章为 **5 战的弧线（5-battle arc）**，自陈留举义起，至酸枣会盟、虎牢叩关止。
**当前切片仅第 1 战可玩**，其余 4 战为路线规划内容（见下方 Roadmap）。

- **第 1 战《陈留起兵》（可玩 / playable now）**
  中平末年，董卓挟天子、暴洛阳。曹操单骑遁出，星驰陈留，散尽家赀、矫诏募义。
  正待发兵讨董，城东北黄巾残党劫掠乡里、断我粮道，倚关门林莽立寨。
  曹孟德遂以此寨为义旗第一血——10×8 等距战场，迎击黄巾。
  - **我方**：曹操（主将/计略·治疗）、夏侯惇（步兵）、夏侯渊（弓）、曹仁（枪）、曹洪（骑）。
  - **敌方**：黄巾渠帅及枪/弓/力士残党；**第 3 回合**关门援军杀出（战场触发器演出）。
  - **胜利条件**：全歼敌军（`rout`）。**失败条件**：主将曹操阵亡（`leaderDead`）。
  - 含战前动员、战后告捷的原创剧情演出与运镜，胜后自动存档并可返回 hub。
- 第 2–5 战（路线规划）：讨董序幕、汜水/虎牢叩关、酸枣诸侯会盟等篇章。

## 技术 / 架构 (Tech & Architecture)

- 原生 ES Modules，无构建；本地 vendored Three.js（r170，经 importmap 以 `three` 裸导入）。
- 引擎/内容分离、数据驱动：`battle/`、`story/` 为**纯逻辑**（不依赖 Three.js/DOM，可单测）；
  `render3d/` 只按状态作画；`ui/` 为 DOM 覆盖层；三者经 `core/eventBus` + `core/gameState` 通信。
- 持久化用 localStorage；音效用 WebAudio。
