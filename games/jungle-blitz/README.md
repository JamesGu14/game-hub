# 丛林尖兵 JUNGLE BLITZ 🪖

一款原创横版跑射（run-and-gun）游戏，向经典的魂斗罗类游戏致敬。从左到右闯关，
跳跃躲避、八方向射击、捡武器，关底打 BOSS，第 5 关击败最终大 BOSS 通关。

> 专为 7 岁小朋友设计：**血量条 + 多条命 + 复活检查点 + 无限续关**，永远不会从第 1 关重来，挫败感极低。

## 玩法

- 5 个主题关卡：丛林入口 → 河流大桥 → 敌军基地 → 瀑布悬崖 → 核心基地。
- 每关结尾有一个小 BOSS；第 5 关结尾是多阶段最终大 BOSS「核心」。
- 4 种武器（步枪 / ⭐散弹 / 机枪 / 激光）+ 2 种道具（🛡 护盾 / ❤️ 补血），打补给舱或碰一下即可获得。
- 被击中扣一格血并短暂无敌闪烁；血量归零掉一条命，从最近旗帜检查点满血复活。

## 操作

| 动作 | 键盘 | PS 手柄 |
|---|---|---|
| 左右移动 | `A`/`D` 或 `←`/`→` | 左摇杆 / 方向键 ←→ |
| 向上瞄准 | `W` 或 `↑`（按住） | ↑ / 摇杆上 |
| 蹲下；空中向下瞄准 | `S` 或 `↓`（按住） | ↓ / 摇杆下 |
| 跳跃 | `K`（或 `空格`/`Z`） | ✕ |
| 射击（**按住自动连发**） | `J`（或 `X`） | □ / R1 |
| 暂停 / 继续 | `Esc` / `P` | Start |
| 静音 | `M` | — |

**八方向瞄准**：站立平射；按住「上」朝上射、配合左右斜上射；空中按住「下」朝下射；地面按「下」蹲伏贴地射。

## 运行

本游戏是纯静态页面，**无需编译**。在项目根目录运行：

```bash
./start.sh           # 默认 http://localhost:8000/
```

然后在游戏中心（HUB）点击「丛林尖兵」卡片即可游玩，也可直接打开
`http://localhost:8000/games/jungle-blitz/index.html`。

> 小贴士：网址后加 `?stage=N`（N=1~5）可直接从第 N 关开始，方便复习某一关或测试。
> 例如 `…/index.html?stage=3` 直接进第 3 关。

## 说明

- 所有美术均由 canvas 几何图形在运行时绘制，音效为 Web Audio 实时合成——**不使用任何第三方角色、像素图、音乐或受版权保护的素材**。角色、关卡、敌人、BOSS、命名全部原创。
- 最高分与最远关卡保存在浏览器 `localStorage`。

## 代码结构

```
src/
  config.js   数值常量（物理/武器/敌人/BOSS/计分）
  levels.js   5 关数据 + BOSS 配置
  util/math.js 纯逻辑工具（含单元测试）
  input.js    键盘 + 手柄输入
  world.js    地形/平台/相机
  player.js   玩家：移动/跳跃/瞄准/血量
  bullets.js  子弹（玩家 + 敌人）
  powerups.js 补给舱与道具
  enemies.js  敌人类型与 AI
  bosses.js   5 个 BOSS 行为
  game.js     状态机与系统调度
  render.js   绘制（含 HUD / BOSS 血条）
  main.js     启动与主循环
tests/        node --test 单元测试（math / levels）
```

测试：`node --test 'games/jungle-blitz/tests/*.mjs'`
