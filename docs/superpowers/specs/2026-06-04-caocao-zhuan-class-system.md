> 原创致敬作。采用原版《三国志曹操传》的**通用兵种命名与体系结构**（事实性设定）+ 武将史实定位；

## 0. 五维能力含义
| 缩写 | 全称 | 作用 | 由武将哪项换算 |
|---|---|---|---|
| 攻 | 攻击力 | 物理伤害 | 武力/2 + 兵种成长 |
| 精 | 精神力 | 计略威力 + 计略抗性(魔抗) | 智力/2 + 兵种成长 |
| 防 | 防御力 | 减免物理伤害(对计略无效) | 统率/2 + 兵种成长 |
| 爆 | 爆发力 | 连击/会心发动率与威力 | 敏捷/2 + 兵种成长 |
| 士 | 士气 | 命中/反击/必杀发挥 | 运气/2 + 兵种成长 |

伤害公式（忠实参考，实现期可微调）：
- 物理 ≈ `((攻 − 防)/2 + 等级 + 25)` × 兵种相克 × 地形 × 装备
- 计略 ≈ `((自精 − 敌精)/3 + 等级 + 25)` × 计略系数 × 装备
- 命中：物理看 爆/士 差；计略看 精/士 差。

## 1. 攻击范围 footprint（第 1 点：点选时高亮，引擎需支持的形状）
`attackShape = { type, min, max }`：
- `cross`（十字）：曼哈顿距离 [min,max] 的正交格。melee 初/中级 = `cross 1`（上下左右 4 格）。
- `star`（八向）：切比雪夫距离 1 = 周围 8 格（含斜角）。melee 高级转职解锁。
- `diamond`（远程菱形）：曼哈顿 [min,max]，弓系用（如 [1,2]/[2,2]/[1,3]）。
- `area`（炮车群体）：以目标格为心曼哈顿半径 N 的 AOE。
- 计略系：基础物攻 `cross 1`（弱）；真正输出靠计略，射程见各计略。

**高亮 UX（曹操传式）**：点选我方单位时同屏——**蓝**=可移动格；**红**=移动后按 footprint 可攻击到的威胁范围；选定落点后再高亮该点的可攻目标。

## 3. 转职（印绶）
- 等级 1–50；**Lv15 转中级、Lv30 转高级**，各需消耗一枚**印绶**道具（关间整军里用）。
- 30 级以上用印绶可**选中级或直接转高级**。
- 升兵种：HP/MP/移动/攻击范围(footprint 升级) + 五维跃升；解锁更高阶计略（计略系）。
- **君主**线（群雄→英雄→霸王）可随主线/剧情成长，非靠印绶（或视为固定）。

## 4. 各职业攻击方式 + 技能/等级（本作精简采用；原版进程为参照）

**物理系（普攻为主，保留少量自用计略）**
- **君主**：普攻；计略 Lv1 旋风(风·AOE小伤)、Lv6 小补给(自疗)、Lv10 **霸气**(自身全属性+20% 数回合)。
- **步兵**：普攻；特技 高防·**反击强化**(剑系反击)·ZOC 卡位。无计略。
- **骑兵**：普攻；特技 **突击**(冲锋附伤)·高机动。无计略。
- **弓兵**：远程普攻；特技 远程压制·高士气易**致命一击**。无计略。
- **弓骑兵**：远程普攻；特技 **不被兵种相克**·机动。无计略。
- **武术家**：普攻；特技 S爆发(连击/会心)·林地强；计略 Lv1 气合(自身攻+)、Lv15 钝兵(降敌攻)。

## 6. 实现影响（审定后写成 plan → Workflow 建造）
1. `data/classes.js`：11 系 × 3 段 = 定义（attackShape/moveType/mov/growth/promoteTo 链/各 Tier 数值/可学计略与等级）。
2. `data/generals.js`：按 §5 重排全部 classId + 起始 Tier/等级；五维改为 武力/智力/统率/敏捷/运气 驱动（或保留现 atk/def/int/spd 并加 爆/士）。
3. **攻击范围高亮**（第 1 点）：`battle/` 加 `attackReach(unit)`（按 attackShape，含 cross/star/diamond/area）；`render3d` 红色攻击高亮；`main.js` 选人叠加蓝+红。
4. **印绶转职**：`data/items.js` 加印绶；`battle/promotion.js` 处理 Lv15/30 转职（选中/高）；`ui/intermission` 加转职入口与确认。
5. **逐级技能习得**：`battle/leveling` 升级时按职业表授予计略/特技；扩充 `data/skills.js`（新增约 16 个计略）与 `skillEngine`（霸气/回归/觉醒/范围眩/全场随机 等新效果）。
6. **物理特技**：突击/连击/反击强化/致命/不被相克/山林强 等被动，接进 combat/duel。
7. 3D 外观：按新兵种(马/弓/法师/炮)调 unitFactory；更新单测（footprint/转职/新计略）。

> 工程量较大（≈ 一次 P2-skills 量级或更大）。建议分阶段：A 职业数据+footprint高亮 → B 印绶转职+逐级习得 → C 新计略+物理特技 → D 重排名册+联调+实玩。
