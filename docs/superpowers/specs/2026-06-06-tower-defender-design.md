# 成都保卫战 — 三国塔防设计文档

> 类型:Web 回合(波次)制实时塔防 · 单人 · 三国蜀汉题材
> 位置:`game-hub/games/tower-defender/`(显示名「成都保卫战」)
> 日期:2026-06-06 · 状态:设计定稿待审(三国武将主题版)
> 美术基准:用户提供的手游三国塔防参考图(近正俯视 + 精细卡通武将立绘)

一句话:**你执掌蜀汉,死守国都成都。** 以**五虎上将 + 诸葛亮**为防御「将塔」,抵御**南蛮、东吴、曹魏**三大势力名将的轮番来犯。沿弯曲蜀道在路边将位上布将设防,击杀掉金、再调更多名将,撑过全部波次即守城成功。关卡按战役由易到难(南征 → 抗吴 → 北伐),带存档与选关。

---

## 1. 核心玩法循环(Core Loop)

**实时塔防,「回合 = 波次」。** 游戏时间连续流动:

1. **备战阶段**:每关开局、每波之间有倒计时(默认 30s)。期间敌不出,你布将/升级/拆除。
2. **来袭**:倒计时归零(或点「**提前出兵**」),本波敌军从各敌营涌出,沿各自蜀道扑向成都。
3. **战斗**:将塔**自动出手**(按各自目标模式选敌),击杀**掉落金币**;可在战斗中继续花钱布将/升级。
4. **结算本波 → 回备战阶段**,直到本关全部波次结束。

- **提前出兵奖励**:点「提前出兵」立即开打,奖励金币 = 剩余备战秒数 × 2。
- **速度控制**:1× / 2× 快进 + 暂停(右上角)。

> 设计取舍:用户原话「回合制 + 每 1 分钟一波」落地为**实时塔防**,「回合」即「波次」,波间有备战回合 —— 最主流、最耐玩。

---

## 2. 地图与敌军行进

- **纯俯视棋盘式地图**(摄像机近正俯视地面,武将 billboard 立绘;详见 §11)。
- **中心 = 成都**(蜀汉都城,中式城楼,占地约 2×2 格)。
- **四周 = 2–8 座敌营**,数量随关卡难度递增(难度主旋钮),阵营按战役而定(南蛮寨 / 吴营 / 魏营)。
- 每座敌营有一条**固定弯曲蜀道**(刻意拐弯拉长行进)通向成都。**敌人只走道路**(飞兵例外,见 §5)。
- **将塔只能布在路边预设的「将位」**(固定点位,非自由摆放),分布于道路两侧,决定火力覆盖。
- 非道路、非将位区域为草木/山石装饰(不可布防)。

**行进模型**:道路是一串 waypoint;敌人沿 waypoint 匀速推进(`pathSystem`),无 A* 寻路 —— 降复杂度、路线清晰。飞兵走「敌营→成都」直线,无视道路。

---

## 3. 胜负条件(守城战)

- **成都城防值(默认 20)**。敌人冲到中心即对成都造成伤害并消失:步卒/轻骑/飞兵/方士 各 1,重甲/藤甲 2,**BOSS 5**。
- **失败**:成都城防归零。
- **敌营攻陷**:每关有一张**波次表**,每波由某座/某几座敌营出兵(可多营同时来袭);某敌营被分配的波次全部清光后,该敌营标记为「**攻陷/熄火**」。
- **守城成功(通关)**:撑过本关所有波次且成都未破 ⇒ 全部敌营攻陷 ⇒ 胜利。
- 「2–8 座敌营」天然是难度刻度:营越多 = 来袭方向越多、总波量越大、同时压力越高。

## 4. 蜀汉六将·将塔

**6 座将塔 = 五虎上将 + 诸葛亮**,沿用既有塔机制,按武将历史招牌对应。全部从第 1 关即可调用(以金钱为门槛,不另设解锁)。每将可**原地升级 1→2→3 级**(造价递增,数值提升,立绘升阶);**满级(L3)解锁专属招牌技**;可**拆除返还 60%**。

| 将 | 机制(原塔) | 伤害 | 目标 | 造价* | L3 招牌技 | 史实 |
|---|---|---|---|---|---|---|
| 🏹 **黄忠** | 单体速射·前期主力 | 物理 | 地+**空** | 70 | **百步穿杨**(被动):25% 必定暴击(×2.5)·无视护甲 | 神箭手 |
| 🪨 **张飞** | 范围溅射·清群 | 物理 | 仅地 | 110 | **当阳怒吼**:溅射范围内短暂定身 | 万人敌·当阳桥 |
| 🌊 **关羽** | 减速控制(水攻) | 谋略(无视护甲) | 地+**空** | 120 | **水淹七军**:大范围重减速 + 持续伤 | 水淹七军 |
| 🎯 **赵云** | 高单体·狙 BOSS | 物理 | 仅地 | 160 | **七进七出**:击杀目标后立即连射下一个 | 长坂坡 |
| 🐎 **马超** | 沿道路冲锋·多目标 | 物理 | 仅地 | 140 | **西凉突阵**(被动):沿蜀道命中身前一段路多敌 + 击退 | 西凉铁骑 |
| 🔥 **诸葛亮** | 火攻灼烧·蔓延·克藤甲 | 火(持续) | 地+**空** | 150 | **火烧藤甲**:对南蛮藤甲超额灼烧 | 火烧藤甲军 |

\* 示意值,平衡用起点。升级:L2 ≈ 造价 ×1.0,L3 ≈ 造价 ×1.6。

### 目标选择(Targeting)

每座将塔有**可切换的目标模式**,默认「**最前**」(离成都最近 = 威胁最大)。点击将塔即可切换:**最前 / 最后 / 最强(血最多)/ 最弱(血最少)**。
反制**方士**(后排奶妈)的解法:把若干将设为「最弱/最后」专点掉它。

### 克制关系(策略核心)

- 物理(黄忠/赵云/马超)× 藤甲 = **弱**(抗物理 50%);**诸葛火攻 × 藤甲 = 克**(怕火 +50%);关羽谋略(水攻)**无视护甲** → 对藤甲走常规伤害(不被物理抗减)。
- **飞兵 = 仅 黄忠 / 关羽 / 诸葛亮(防空将)可打**;张飞/赵云/马超 对其无效 → 逼迫布防空。
- 关羽减速 × 轻骑/狼骑 = **克**(拦高速)。
- 赵云高单体 × BOSS/重甲 = **克**。
- 目标模式「最弱/最后」× 方士 = 点杀奶妈。

## 6. 经济与数值(默认,可调)

- 成都城防 **20**;起始金钱随关卡 **200 → 320**(无屯田经济塔,**金钱全靠击杀掉落** → 起始略上调)。
- 击杀掉金:见 §5。
- 将塔造价/升级/拆除:见 §4。
- 备战时间:开局 + 波间各 **30s**;提前出兵奖励 = 剩余秒 ×2。

> 数值集中在 `data/balance.js` 与各关 `level.scale`,便于 playtest。

## 7. 关卡 · 战役推进 · 星级 · 解锁

**v1 共 8 关**,按战役 **南蛮 → 东吴 → 曹魏** 由易到难;敌营数 **2 → 8** 递增。兵种原型逐关引入(一次加一种威胁)。

| 关 | 战役 | 势力 | 敌营 | 新增威胁 | 末波 BOSS | 波数* |
|---|---|---|---|---|---|---|
| L1 | 南征·序战 | 南蛮 | 2 | 蛮兵 / 狼骑 | —(教学关·无 BOSS) | 8 |
| L2 | 南征·密林 | 南蛮 | 2 | + 名将 BOSS 机制 | 木鹿大王(驱兽) | 9 |
| L3 | 南征·藤甲 | 南蛮 | 3 | + **藤甲兵(怕火)** | 兀突骨 | 10 |
| L4 | 抗吴·荆州 | 东吴 | 4 | + **飞兵(飞鸢)** | 甘宁 | 11 |
| L5 | 抗吴·夷陵 | 东吴 | 5 | + **方士(吴术士)** | 陆逊 | 12 |
| L6 | 北伐·陇右 | 曹魏 | 6 | 虎豹骑 + 全兵种 | 张辽 | 13 |
| L7 | 北伐·街亭 | 曹魏 | 7 | 重甲铁骑加量 | 张郃 / 许褚 | 14 |
| L8 | 北伐·决战 | 曹魏 | 8 | 全兵种 + 多 BOSS | **司马懿** | 16 |

\* 示意。全关总波数,按波次表分配到各敌营。

- **星级(3★)**:按守城后成都剩余城防 —— 满防(20)= 3★,≥50% = 2★,通关但 <50% = 1★。
- **解锁制**:守住第 N 关解锁第 N+1 关。
- **选关**:进入游戏可选「任意**已通关**关卡」重玩,或直接进「**下一未通关**关卡」。

## 8. 存档(localStorage)

单档自动存。Key:`gh.tower-defender.save.v1`。

```json
{
  "version": 1,
  "unlockedLevel": 3,
  "stars": { "1": 3, "2": 2 },
  "settings": { "muted": false, "speed": 1 }
}
```

- `unlockedLevel`:已解锁的最高关(1-based)。
- `stars`:各已通关关卡的最佳星数(取最大)。
- 损坏/缺失时回退初始档(仅 L1 解锁)。

## 9. 操作 · HUD · 控制

- **鼠标为主**:点空将位 → 选将布防;点已有将 → 升级 / 拆除 / 切目标模式 / 满级释放招牌技说明;点敌 → 查看血量。

## 11. 美术方向(以用户参考图为基准)

**目标观感**:经典手游三国塔防(类《王国保卫战》)——

- **摄像机**:地面**近正俯视**(蜀道/将位像盘面一眼看全),**武将 billboard 立起、正面朝玩家**(看得见脸/兵器/铠甲),整体拉远、单位偏小。**非** 3/4 强斜视,**非**扁平俯视色块。
- **画风**:鲜艳饱和卡通,描边 + 卡通光影;草木/山石/旌旗装饰;选中将位发光圈;击杀金币飘字。
- **题材**:三国蜀汉。中心成都中式城楼;六将各具辨识立绘(关羽红脸长髯青龙刀、张飞豹头环眼、赵云白袍银枪、马超狮盔银甲、黄忠老将硬弓、诸葛羽扇纶巾);三势力小兵与 BOSS 立绘各异(南蛮赤膊藤甲 / 东吴水军 / 曹魏玄甲)。

**实现 = 精细 2D sprite 素材管线**(本作引入 `assets/`,不同于站内零素材游戏):

- 用 AI **批量生成统一画风透明底 PNG**:6 将(各含升阶态)、各势力 6 类兵 + 名将 BOSS、成都城楼、各势力敌营、蜀道/地块/装饰、招牌技与命中特效。
- **v1 范围**:每将 1–3 张(升阶)、每势力每兵 1 张、各 BOSS 1 张、成都、敌营、若干地块/装饰;动感用**变换补间**(浮动/缩放/受击闪白),**不做逐帧动画**(后续可扩)。
- **全项目最大工作量与风险点**:画风一致性、透明底质量、武将辨识度、迭代成本。先打通「生成→命名→接入→预加载」一条龙,再批量铺。

## 12. 技术架构

**推荐**:原生 JS **ES Modules、零构建**(同 caocao-zhuan)+ **Canvas 2D** 渲染。

- 渲染:`drawImage` 贴 sprite;自写 `requestAnimationFrame` 循环(固定步长 + 速度倍率);近俯视盘面 + billboard 精灵 + **y-sort** 解决遮挡。
- 资源:`assets/` 存 PNG,启动**预加载**后再进游戏;关卡/数值为 JS/JSON 数据。
- 存档:localStorage。测试:`tests/*.test.mjs`(Node test runner)覆盖纯逻辑。
- 注册:`js/games.js` 加卡片(id `tower-defender`,标题「成都保卫战」,副标题「三国塔防 · 五虎守成都」,蜀汉红金主题色)。

**备选渲染(已评估)**:Pixi.js/WebGL(精灵极多时更快,+依赖)/ DOM 精灵(简单但实体一多即卡)。**选 Canvas 2D** —— 够用、无依赖、合站内风格。

## 13. 测试策略

纯逻辑与渲染解耦,用 Node test runner 覆盖:

- **targeting**:各目标模式选中正确目标(「最弱」点方士;防空将不选/可选地空)。
- **combat**:克制矩阵(物理×藤甲、**诸葛火×藤甲**、关羽水攻×藤甲、防空将×飞兵)、溅射、灼烧蔓延、减速施加、方士治疗。
- **signatures**:6 将 L3 招牌技(百步必爆、当阳定身、水淹大范围减速、七进七出连射、西凉穿透击退、火烧藤甲超伤)。
- **economy**:掉金、布防/升级/拆除返还、提前出兵奖励、买不起拦截。

### 17.1 将塔硬参数(射程 = 格 · 间隔 = 秒)

| 黄忠 | 3.5 | 0.7 | 9 | 物理 | 单体·可空 |
| 张飞 | 2.5 | 1.8 | 20 | 物理 | 溅射半径1格·仅地 |
| 关羽 | 3.0 | 1.5 | 10 | 谋略 | 命中减速40%/2.5s·可空 |
| 赵云 | 5.0 | 2.5 | 48 | 物理 | 高单体·仅地 |
| 马超 | 3.0 | 1.2 | 14 | 物理 | 沿路命中身前≤3敌·仅地 |

### 17.3 敌军规则

- **BOSS**:L1–7 = 高血 + 扣城5 + 轻抗(物理−10%),沿路推进、**无主动技**;**司马懿(L8 终)** 带 2 技:① 每 15s 召唤 2 名魏卒;② 推进途中每 8s 震慑身边 1 座将塔、停火 2s。
- **方士**:治疗范围 1.5 格、每 1s 回 8 HP;多方士对同目标可叠加,但每目标每秒回血**封顶 24**;**方士 HP 设为全场最低档 → 「最弱」模式可靠点杀**(解漏洞#5)。
- **伤害类型**(物理/谋略/火 独立)与抗性:南蛮藤甲 物理×0.5 / 火×1.5 / 谋略×1.0;吴·魏重甲 物理×0.6 / 火×1.0;余 ×1.0。
- **状态机**:减速 / 灼烧 / 定身 / 治疗 各自独立计时。定身>0 时移动=0(减速计时继续);多重减速**取最强不叠加**;灼烧最多叠 3 层;治疗按净值抵消 DoT。
- **飞兵**:敌营中心→成都中心走直线(2D 平面,忽略高度);仅防空将可锁定;**飞兵与 BOSS 分波出现**(解漏洞#2);出怪由波次表分批刷出。

### 17.4 路径 · 将位 · 判定

- **waypoint**:`Path = [{x,y}, …]` 折线(格坐标);敌按自身速度沿线段匀速推进;朝向取当前线段方向 → 精灵左右翻转。v1 无停顿/变速点。
- **将位**:每关 `level.slots = [{x,y}]` 显式列出(L1≈8 → L8≈18 个);**设计约束:每条蜀道每段都落在某将位最小射程(2.5格)内**,确保无天然漏怪、3★ 理论可达。
- **棋盘**:标准 **16×11 格**;成都居中占 2×2;敌营占 1 格、贴边。
- **「到达中心」判定**:蜀道末 waypoint 落在成都城门(2×2 边缘);敌中心距该点 ≤0.3 格即到达 → 扣城并消失(点判定,无碰撞体积)。

### 17.5 波次表结构

```js
level.waves = [
  { waveId, startDelay,                 // 距上波结束的延迟(s)
    spawns: [
      { campId, pathId, enemyType, count, spawnInterval, leadDelay }
    ] }
]
```

同波可多营/多兵种混出;某营被分配的 spawns 全部出完 → 清光后该营「攻陷」。`level.scale` 统一缩放敌方 HP/掉金。

### 17.6 经济(防滚雪球)

- 波间金钱**累积不清零**;每关初发 `startGold`(200→320)。
- **提前出兵奖励 = 剩余备战秒 ×2,单波封顶 30 金**(解漏洞#4)。
- 每清完一波 +固定清怪奖励(如 15 金,高关更高)平滑后期;无硬金钱上限(造价自然约束)。

### 17.7 时间 · 操作 · 失败

- **单一游戏时钟**:1×/2× 等比缩放全部模拟(敌、塔CD、弹道、debuff、备战倒计时);暂停冻结全部。
- 热键:选将 **1–6**;**`空格`暂停 · `F` 快进切换**(解原 1/2 冲突);`ESC` 菜单。
- **失败 = 整关重来**(将塔/金钱清空,回本关备战);不扣星、可无限重试。

### 17.8 存档 · 架构数据流

- 存档 `version`:读到低版本 → 尝试迁移、失败回退初始档;**多设备不同步**(localStorage 已知限制,v1 不解)。
- 系统**事件解耦**:`combatSystem` 击杀 → emit `enemyKilled` → `economySystem`(掉金)/`victorySystem`(计数)监听;`waveSystem` 向 `pathSystem` 注入新敌;统一以中心 `gameState` 读写,避免硬耦合。
