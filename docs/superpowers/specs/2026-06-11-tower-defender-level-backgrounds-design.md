# 成都保卫战 · 关卡背景特色化(地貌拼块)设计 spec

> 2026-06-11 · brainstorming 逐节确认产物。目标:替换 50 关千篇一律的双色棋盘格,让每章有专属地貌主题、每关有种子驱动的独特地表布置。

## 0. 背景与目标

**现状**:`board.js` 每帧画 24×14 双色棋盘格,颜色取自 faction tint——5 章实际只有 2 套观感(魏=冷灰绿、吴=青)。板型/路线/玩法地形已 50 关全唯一,单调的纯粹是地表视觉层。

**目标**:
1. 5 章各一套地貌主题(调色盘/拼块/小景/地标/轻动效),路色随章换
2. 同章 10 关靠关卡号种子产生不同布置——50 关张张不同
3. 精修观感六件套:软边地貌、描边+投影小景、道路磨损、每关 1 地标、章节暗角、格子色抖动
4. 战斗帧性能 ≥ 现状(离屏烘焙后帧内只贴 1 张图)

**非目标**:不改玩法(路线/将位/地形机制/数值零变动);不引入新 PNG 资产;不做天气系统(L50 大雨保持现状)。

## 1. 已确认决策(brainstorming Q&A 记录)

| 问题 | 决策 |
|---|---|
| 特色粒度 | 章主题 + 逐关种子变化(否决:仅 5 套章主题 / 50 关手工) |
| 风格方向 | **C · 地貌拼块**(看图选,否决:A 细腻格子 / B 有机草地) |
| 5 章主题 | 翠野平原 / 官渡河滩 / 江东水乡 / 蜀道松山 / 夷陵焦土,全部认可 |
| 精修度 | **全套 6 项**(用户:「全部认可,但需要再美化一些」→ 打样版 vs 精修版对比后选 A) |
| 动效预算 | 静态为主 + 每关 2-3 处章节性轻动效(否决:全静态 / 丰富动效) |
| 技术路线 | **程序化矢量 + 离屏烘焙**(否决:预生成 PNG / 混合贴图地标) |

## 3. 架构与渲染流水线

**文件变更**:
```
+ src/data/chapterThemes.js   纯数据(§2 全部入此;铁律:render-free、零随机、加载期无 Date/Math.random)
+ src/render/ground.js        computeGroundLayout(level)纯函数 + bakeGround(level,layout) + drawGroundAccents(ctx,state)
~ src/render/board.js         棋盘格块(L15-21)→ 贴烘焙图;BAL.GROUND_THEMES=false 走旧分支
~ src/main.js                 enterLevel 进关时烘焙一次(applyResume 内部走 enterLevel,同口),缓存挂模块级(键=level.id)
~ src/data/balance.js         GROUND_THEMES: true(回滚开关)
```

**战斗帧层序**(只第一层是新的,其余现状不动):
```
贴地表烘焙图(1×drawImage) → drawTerrainBase(地形基底) → 蜀道(改:用章路色+缘+磨损线)
→ drawTerrainFx(地形特效) → drawGroundAccents(轻动效,新) → 暗角(帧内 1 个径向渐变,进关时创建缓存;画在路之后才能压住路的边角) → 将位虚线 → 敌营/成都建筑 → 实体/天气
```
注:路画在烘焙图之上保持现状管线不变,但路色从 `tintOf(faction)` 改读章主题(回滚开关下仍读 faction tint)。

**烘焙**:2× 板像素(1728×1008,RGBA ≈ 7MB)一次性离屏绘制:弱格子 → 色抖动格 → 软边拼块 → 拼块原生小景 → 散布小景 → 地标(投影+描边)。暗角不进烘焙(见层序,需压住路)。窗口 resize 不重烘(等比贴放);进关重烘。目标 < 30ms。

**软边实现兼容**:优先 `ctx.filter='blur(3px)'`(仅烘焙时,帧内不用 filter);特性检测不支持(旧 iPad Safari < 17.4)→ 退化为同心放大三层低 alpha 叠加,观感接近。

**确定性**:seed = `'ground-' + level.id` → `makeRng`(core/rng.js,mulberry32)。同关永远同布置;轻动效仅 time 驱动(沿现有火苗/波光范式),零 Math.random。

## 5. 布置算法(computeGroundLayout,纯函数、可单测)

输入 `level`(含 cols/rows/paths/slots/castle/camps/terrain/chapter/id),输出:
```js
{ jitterCells: [{x,y,colorIdx}], patches: [{kind,cx,cy,lobes:[{dx,dy,rx,ry}]}],
  decors: [{kind,x,y,variant}], landmark: {kind,x,y}, accents: [{kind,x,y,phase}] }
```

1. **禁放格**:路径 waypoint 段经过的格 + 沿路 1 格缓冲(拼块用;小景仅禁路径格本身)、将位格、城堡 w×h + 名牌下沿 1 格、敌营格 + 名牌下沿 1 格、玩法地形格。
2. **色抖动格**:自由格的 12-18% 种子抽样。
3. **拼块** 2-4 块:锚点=有 2×2 自由邻域的格,种子抽;blob = 2-3 椭圆瓣(半径 1.2-2.5 格)叠加;瓣不越禁放格(锚点约束保证主体,溢出裁剪可接受——拼块是低对比装饰,压到缓冲区边缘无害,但不得压路径格/地形格/将位格,越界瓣收缩半径重试 ≤3 次后放弃该瓣)。
4. **小景** 10-16 个:章节池种子抽;每格 ≤1;花田之花/树丛之树/旱田留白等「拼块原生小景」由 patch painter 自带,散布小景避开拼块内部。
5. **地标** 1 个:池内种子选型;选位=自由格中与城堡距离 > 4 格、且 2×2 邻域自由、取候选里离路径最远者。
6. **亲水加权**(第2章):芦苇/沙洲候选格若邻接 river/shallow 地形则权重 ×3。
7. **轻动效** 2-3 处:从已布小景/地标里选可动项(章 accent 类型),记录锚点+相位。

## 6. 轻动效(drawGroundAccents)

| 章 | 动效 | 公式约定(t=state.time) |
|---|---|---|
| 1 | 野花微闪 | alpha = .6 + .4·sin(t·2 + x·5+y·3) |
| 2 | 芦苇摆 | 苇顶 x 偏移 = sin(t·1.5 + hash)·3px |
| 3 | 竹叶摇 | 叶端绕竿小幅旋摆 ±8° |
| 4 | 狼烟 | 贝塞尔 2 控制点随 sin 摆(城堡烟雾同式,细灰白版),自石塔顶升起 |
| 5 | 红叶飘 | 叶心 = 锚点 + 椭圆轨迹(rx12,ry6,θ=t·0.3+i·2.1) |

性能预算:每关 ≤3 处 × ≤10 draw call,远低于现有地形特效。

## 7. 边界情况

- **L50 大雨**:第5章主题照常烘焙;雨丝/压暗(drawWeather)在实体层之上,无冲突。
- **狼烟降级**:第4章地标为栈道架(非石塔)→ 狼烟改为蕨丛微动;通则:accent 按「实际布上的可动项」选,可动项不足则该关动效数自然减少,0 处合法。
- **空间不足**:拼块/小景/地标按候选格数自动缩量,下限 0,不报错不死循环(重试上限硬编码)。
- **续玩(applyResume)**:走 enterLevel 同一烘焙入口,无特殊处理。
- **回滚开关关闭**:格子/路色全回 faction tint 现状,新代码路径整体短路。

## 8. 可读性护栏

1. 装饰层全部画在玩法地形之下;玩法地形(高饱和+描边+动效)辨识度只升不降。
2. 装饰色饱和度贴近草色族(Δ饱和 ≤15%),描边亮度低于地形描边;禁用红色系警示色(落石警示圈专属)。
3. 路径格、将位格零装饰;将位虚线框/名牌/建筑投影规格不变。
4. 暗角 alpha ≤ .26,不影响边角将位可读。
