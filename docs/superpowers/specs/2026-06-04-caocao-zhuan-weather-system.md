# 《群雄逐鹿·孟德篇》天气系统 — 设计稿（待审）

> 原创致敬作。沿用原版《三国志曹操传》的天气×兵种×地形「三角博弈」机制结构（事实性设定），
> 数值/规则为本作自定。状态：**待 James 审阅**。

## 1. 天气类型（每战一个初始天气，可被技能/事件改变）
| 天气 | 主要影响 |
|---|---|
| 晴 | 基准；火系正常/略强；招牌火系大计略(朱雀类)**仅晴可用** |
| 雨 | **火系威力↓或不可用**；水系↑；雷系(青龙类)**需雨/雪**；泥泞地形移动↑成本 |
| 雪 | 火系↓；雷系可用；全体/部分兵种移动↓；视野略降 |
| 雾 | **远程(弓/弓骑/炮)射程↓1 且命中↓**；近战不受影响；视野↓ |
| 阴 | 中性；阴系大计略(玄武类)**仅阴可用**；火系略弱 |

> 风系(旋风/沙暴类)**不受天气影响**（但受地形：林/城内不可用）。

## 2. 数据与改变
- `map.weather`：初始天气（数据驱动；缺省 晴）。
- **改变途径**：
  - 计略：`昙天`(→阴)、`借东风`(→风/助火)、`祈晴`(→晴)等（君主/风水士/谋士可学）。
  - 剧情触发器：`{on:..., setWeather:'rain'}`（如赤壁/雨战桥段）。
  - 可选：每 N 回合随机轻微漂移（默认**关**，保证可复现/可控）。
- 当前天气在 HUD 顶部以图标 + 文字显示，悬停看影响说明。

## 3. 与计略联动（扩 SkillDef）
```js
weather: { require:['sun'], blockedIn:['rain','snow'], powerMod:{ rain:0.5, snow:0.7, sun:1.2 } }
```
- `require`：仅这些天气可用（如 朱雀=['sun']、玄武=['cloudy']、青龙雷=['rain','snow']）。
- `blockedIn`：这些天气不可用/威力归零（如 火系 blockedIn rain/snow）。
- `powerMod`：按天气调威力（火系晴↑雨↓、水系雨↑）。
- 风系标 `weatherImmune:true`。

## 4. 与战斗/移动联动
- **雾**：远程兵种 `attackShape` 的 max −1，命中 −15%（近战不变）。
- **雨/雪**：指定地形(泥/路)移动成本 +1（数据可配）；雪可全局移动 −0（先轻量，仅泥泞）。
- 物理攻击本身不受天气直接影响（除雾对远程）；天气主要作用在**计略**与**远程/视野**。

## 5. 实现要点（并入实现 plan）
1. `battle/weather.js`：天气状态 + `setWeather` + `weatherMods(skill|unit)` 查询。
2. `skillEngine`：施法可用性(require/blockedIn) + 威力(powerMod) 接天气。
3. `combat`/`attackReach`：雾对远程射程/命中。
4. `pathfind`：雨雪泥泞移动成本（可配、可关）。
5. `scenarioRunner`：`setWeather` 步/触发器。
6. `render3d`：天气表现——雨/雪粒子、雾(fog 加重/降饱和)、晴/阴天空色调；HUD 天气图标。
7. 单测：天气对火/雷/朱雀/玄武 可用性与威力的判定。

## 6. 范围
- 第一章先做：**晴/雨/雾** 三种 + 计略天气规则 + 雾对远程 + 一个改天气计略/触发器；雪/阴随相关计略(青龙/玄武)在后续解锁时补。
