# 极速飞车 TURBO DRIFT — 设计文档

> 伪3D 第三人称竞速游戏，从下往上开，类似 QQ 飞车的简化版。
> 受众：7 岁小学一年级（键鼠 + PS 手柄）。
> 立项：2026-06-03。视觉方向经浏览器伴侣实时原型验证。

## 1. 概述

一款 Web 端伪3D 第三人称赛车游戏（OutRun 式纵深，赛道向玩家扑面、有弯道与坡度起伏）。玩家从画面下方向上行驶，与 3 个 AI 车手比拼名次，3 圈定胜负。核心是 **完整漂移攒氮气** 与 **道具战**，4 条主题赛道，多车通关解锁。全程对 7 岁友好（橡皮筋 AI、撞车不出局、辅助转向、总能完赛）。

技术：纯 HTML + Canvas 2D + ES Modules，无外部资源、无构建步骤，直接静态托管。沿用 game-hub 现有约定。

## 2. 已确认的设计决策

| 维度 | 决策 |
|---|---|
| 视角 | 伪3D 第三人称（segment-projection），已用实时原型验证 |
| 玩法目标 | 与 AI 比名次，3 圈定胜负 |
| 漂移 | 完整漂移系统（简化对 7 岁友好） |
| 美术 | 4 条赛道 4 种主题（卡通日间 / 霓虹夜赛 / 沙漠黄昏 / 雪地夜境） |
| 道具 | 完整道具战，含温和攻击道具 |
| 选车 | 多车 + 通关解锁（4 辆） |
| 赛制 | 3 圈 + 3 个 AI 对手 |
| 儿童友好 | 橡皮筋 AI、撞车不出局、总能完赛、辅助转向 |
| 解锁门槛 | 赛道拿到前 3 即解锁（降低挫败，非必须第 1） |
| 追踪导弹 | 保留但温和：仅让前车打转约 1 秒、有提示音、可被护盾挡 |

```

  style.css
  src/
    main.js           # 入口：状态机、浮层绑定、主循环驱动

    render.js         # 伪3D 渲染：投影、赛道梯形、天空/景物、精灵、HUD、特效
```

## 4. 操作方案（键盘 + 手柄）

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 转向 | ← → / A D | 左摇杆 X 轴 / 方向键 14·15 |
| 加速 | ↑ / W（按住） | RT(7) / ✕(0) |
| 漂移 | 空格（按住 + 转向触发） | L1(4) |
| 放道具 | Z / ↓ | □(2) |
| 放氮气 | 攒气后松漂移触发；或 R1/Shift 主动放 | R1(5) |
| 暂停 | Esc / P | Start(9) |
| 静音 | M | — |

护栏：
- **自动巡航底速**：松开加速也保持一个低速前进，绝不熄火停死。
- **辅助转向**：检测当前赛道 curve，给转向一个温和的自动修正分量，过弯不易冲出。

## 5. 漂移 → 氮气系统（核心手感）

- 按住漂移键 + 有转向输入 → 进入漂移：车头朝行进方向、车身侧滑甩尾、可视火花、底部漂移槽开始填充。
- 漂移持续越久，槽填充越多（分 1/2/满 三档视觉提示）。
- 松开漂移键 → 按已攒档位给一段氮气加速（满槽 = 最长氮气）。
- 主动放氮气：攒有氮气时可用 R1/Shift 立即喷发。
- 儿童友好：进入漂移判定宽容；漂移期间转向更灵但不会失控自旋；氮气期间辅助转向加强。
- 物理量在 `config.js` 暴露：`drift.enterThreshold`、`drift.chargeRate`、`nitro.boostSpeed`、`nitro.durationByCharge[]` 等。

## 6. 道具系统

开过赛道上的道具箱（❓）随机获得一个，同时仅持有一个，使用后清空。

| 道具 | 图标 | 效果 | 时长/规则 |
|---|---|---|---|
| 加速喷射 | 🚀 | 短促提速 | ~1.2s |
| 护盾 | 🛡️ | 抵挡一次攻击/油渍 | 直到被消耗或 ~6s |
| 油渍 | 🍌 | 投在身后，后车压到打转减速 | 留存于赛道 ~8s |
| 缩小闪电 | ⚡ | 其他所有车短暂变小变慢 | ~2.5s |
| 追踪导弹 | 🎯 | 飞向名次紧邻前一名的车，命中使其打转 ~1s | 可被护盾挡，有提示音 |

被攻击的统一表现：**只打转/减速，绝不爆车、不淘汰、不重来**。AI 同样会捡道具并使用（频率受难度参数限制）。

## 7. 四条主题赛道

| # | 主题 | 配色 | 难度特征 |
|---|---|---|---|
| 1 | 草原日间 🌱 | 蓝天 / 绿草 / 糖果色 | 缓弯、平坦，教学关 |
| 2 | 城市夜赛 🌃 | 暗紫夜空 / 霓虹边线 / 城市剪影 | 中速弯 + 起伏 |
| 3 | 沙漠黄昏 🏜️ | 橙金渐变 / 仙人掌 | 长弯 + 大坡 |
| 4 | 雪地夜境 ❄️ | 冷蓝 / 雪松 / 冰面 | 冰面微滑（抓地↓）+ 急弯，最难 |

每条赛道数据：弯道 + 坡度序列（用 `addRoad(n, curve, hill)` 累积构建）、主题配色表、路边装饰精灵种类与密度、道具箱位置、起点/终点线、AI 出生错位。赛道为闭环跑道，3 圈。

## 8. 车库与解锁

开局拥有 1 辆初始车。每条赛道拿到 **前 3 名** 解锁 1 辆，共 4 辆：

| 车 | 极速 | 加速 | 抓地 | 特点 | 解锁 |
|---|---|---|---|---|---|
| 🟦 闪电 | 中 | 中 | 中 | 全能好上手 | 初始 |
| 🟥 烈焰 | 高 | 中 | 低 | 直道快、偏滑 | 通过赛道 1 |
| 🟩 疾风 | 中 | 高 | 高 | 起步快、稳 | 通过赛道 2 |
| 🟪 星耀 | 高 | 高 | 中 | 压轴奖励车（赛道3解锁，正好驾驭最难的赛道4） | 通过赛道 3 |

赛道 4（雪地，最难）为冠军终极挑战，不再解锁新车——玩家用刚拿到的星耀车征服它。车辆数值（极速/加速/抓地）映射为物理参数缩放系数。锁定车在车库灰显并标注解锁条件。

## 9. AI 车手（橡皮筋）

- 每个 AI 沿赛道「理想线」行驶：根据前方 curve 预瞄、过弯减速/漂移，按所驾车性能限速。
- **橡皮筋**：玩家落后超过阈值 → 前方 AI 速度上限略降（等一等）；玩家领先超过阈值 → 落后 AI 速度上限略升（追一追）。强度在 `config.ai.rubberBand` 可调，保证比赛焦灼但玩家努力可赢。
- AI 也会拾取并使用道具，使用频率与目标选择受难度限制（避免 7 岁被连续针对）。
- AI 位置以「沿赛道里程 + 横向 lane」表示，便于名次计算与渲染投影。

## 10. 儿童友好护栏（汇总）

- 自动巡航底速，绝不熄火。
- 撞墙/撞车仅减速打转，**不爆车 / 不出局 / 不重来**。
- 辅助转向降低冲出赛道概率。
- 总能完赛：无超时、无淘汰，跑完即有鼓励性结算（哪怕最后一名）。
- 倒计时 3-2-1-GO、大字名次提示、欢快音效与正向反馈。

## 11. 状态机与主循环

```
menu  →  garage  →  countdown  →  racing  →  finish
 ↑         (选车)     (3-2-1)      (主循环)    (结算+解锁)
 └───────────────────────────────────────────────┘
                    Esc → pause（racing 时）
```

主循环（固定步长更新 + 渲染分离，保证物理稳定）：
```
每帧：
  累积时间 → 固定步长 update():
    读输入(input.js)
    玩家物理(player.js)：加速/转向/漂移/氮气/辅助转向
    AI 更新(ai.js)：走线 + 橡皮筋 + 用道具
    道具(items.js)：箱体拾取 + 飞行物/油渍判定
    碰撞：车-车、车-墙、车-道具 → 仅减速打转
    名次/圈数(race.js)：过起跑线计圈、按里程排名
    相机跟随玩家
  render(render.js)：天空/景物 → 赛道梯形 → 精灵 → 玩家车 → 特效 → HUD
```

## 12. 渲染（已用原型验证）

经典 segment-projection 伪3D（Jake Gordon 路线，已在 brainstorm 原型中跑通）：

- 赛道按固定段长切分，每段有 `curve`、`worldY`（坡度累积）。
- 相机位于玩家后方略高处；每段世界坐标减相机坐标后 `scale = camDepth / dz` 投影到屏幕，得屏幕 `x/y/w`。
- 从远到近绘制：草地/地面带 → 赛道梯形 → 路肩条纹（rumble）→ 中线虚线。
- 精灵（对手车、道具箱、路边装饰）按所在段 scale 缩放定位，远小近大。
- 近景叠加：玩家车（漂移时侧倾 + 火花 + 氮气尾焰）、HUD（名次 N/4、计时、圈数、漂移槽/氮气条、当前道具）。
- 主题切换 = 替换配色表与装饰精灵集，几何与投影逻辑不变。
- 纯 Canvas 2D 绘制，零外部图像/音频资源。

## 13. 音频（Web Audio 程序化）

沿用项目「无音频资源、纯 Web Audio 合成」做法：引擎声（随速度变调）、漂移摩擦、氮气喷发、道具拾取/命中、撞击、倒计时哔、过线/胜利旋律。受静音开关与首次交互解锁约束。

## 14. 存档（localStorage）

键 `turbo-drift.save`，结构示意（合成值）：
```json
{
  "unlocked": ["lightning", "blaze"],
  "bestLap": { "track1": 41200, "track2": null },
  "lastCar": "lightning",
  "progress": { "track1": "win", "track2": "raced" }
}
```
时间以毫秒整数存储。读档失败时回退到默认（仅初始车解锁）。

## 15. 测试策略

纯逻辑单测（沿用 `games/*/tests` 风格，浏览器内或轻量 runner）：
- 圈数与过线判定（防止倒车刷圈）
- 名次计算（里程排序、并列处理）
- 解锁规则（前 3 名 → 解锁对应车）
- 漂移攒气 → 氮气时长映射
- 道具效果与时长、护盾抵挡逻辑
- 橡皮筋速度上限边界
- 碰撞仅减速、不致死

渲染与手感：人工试玩 + Playwright 冒烟（能进入比赛、能完整跑完 3 圈、完赛触发解锁）。

## 16. 验收标准

1. 从 HUB 卡片可进入游戏，返回 HUB 正常。
2. 伪3D 赛道渲染流畅（目标 60fps，桌面），弯道/坡度观感正确。
3. 键盘与手柄均可完整操作（转向/加速/漂移/氮气/道具）。
4. 漂移能攒氮气并喷发，手感对 7 岁友好。
5. 4 条赛道可玩，主题各异。
6. 3 个 AI 有橡皮筋，比赛焦灼且玩家努力可赢。
7. 道具系统完整，被攻击不爆车/不出局。
8. 撞车不出局、总能完赛、辅助转向生效。
9. 拿前 3 解锁新车，存档持久。
10. 纯静态、无外部资源、无构建步骤。

## 17. 非目标（YAGNI）

- 不做联机/多人。
- 不做真实物理引擎（用够用的运动学近似）。
- 不做 3D（Three.js）——伪3D 已满足且性能更稳。
- 不做账号/云存档。
- 不做赛道编辑器。
- 首版不做天气/昼夜动态变化（主题为静态）。
