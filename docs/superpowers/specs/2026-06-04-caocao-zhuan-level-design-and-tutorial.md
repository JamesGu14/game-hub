# 《群雄逐鹿·孟德篇》关卡设计规范 + 教程/机制解锁节奏 — 设计稿（待审）

> 原创致敬作。逐章交付的「关卡质量基准」与「新系统登场节奏」，与设计语料一致；
> 数值/节奏为本作自定。状态：**待 James 审阅**。

## 0. 定位
逐章交付时各章地图质量、难度曲线、宝物/印绶投放、新机制登场需要一套统一基准，否则章与章之间漂移。本稿是关卡作者（人或 subagent）的检查表。

## 1. 地图规范
| 类型 | 尺寸区间 | 我方可部署 | 敌方数 | 备注 |
|---|---|---|---|---|
| 教学战 | 8×8 ~ 10×8 | 4–6 | ≈ 1.0–1.3× | 少地形干扰，突出单一教学点 |
| 常规战 | 10×8 ~ 14×10 | 5–8 | ≈ 1.2–1.5× | 含 1–2 个地形战术点 |
| 攻坚/关隘 | 12×10 ~ 14×10 | 6–8 | ≈ 1.3–1.6× | 关门(gate)据点 + 狭口 ZOC 卡位 |
| 会战/伏击 | 14×12 ~ 16×12 | 8–12 | ≈ 1.4–1.8× + 援军波次 | **性能拐点**：单位数见 ops 预算 |

- **布局原则**：关隘=单宽狭口配 ZOC（克高机动）；高地(hill/mountain)=弓/弓骑射点；林=盗贼/伏兵；水/桥=分割战场与必经点；撤离/护送点远离起始格；敌援军入口在地图边缘并在剧本标注。
- **可达性/无死锁清单**（接 content-pipeline 的 data-validate）：① deploy/enemies 全在可通行非水格；② 胜利条件可达（据点/出口/护送终点有连通路径）；③ 不留孤立区致敌人永不接敌（rout 卡死）；④ 伏兵出现位不与我方初始重叠。

## 2. 难度递增（引用 balance-master / difficulty 唯一权威）
- 敌方平均等级 ≈ 曹操等级 + `difficulty.enemyLvDelta`；逐战再 +1~2 等级 / +1~2 单位。
- 攻防HP/MP 区间、一击占比、TTK 目标一律以 **balance-master** 为准，本稿只给「每战相对上一战的增量步长」。
- boss 战：1 boss（多阶段/狂暴，见 enemy-ai）+ 护卫 + 杂兵；boss 不应能一击秒我方核心（ONE_SHOT_CAP）。

## 3. 宝物 / 印绶 / 经济投放对齐
- **宝物**：每章 1–2 件，绑定击杀/剧情（见 item-system 起步 8 件）；获得等级 = 曹操等级/4+1。
- **印绶**：章末给 1 枚为基准节奏，对齐 progression 转职阈值（Lv15/30）；商店亦可高价限量购（economy）。
- **战利品现金**：锚 balance-master `moneyMul` 与 economy 公式；商店解锁（`shop.unlockBattle`）对齐章节推进。

## 4. 首 5 战 · 机制解锁节奏表（避免一战塞太多）
| 战 | 战役 | 首次登场机制 | 教程要点 |
|---|---|---|---|
| 1 | 陈留起兵 | 移动 / 普攻 / 兵种相克 / 回合 / 胜负 / 攻击范围高亮 | 最基础操作；tutorial 覆盖层手把手 |
| 2 | 会盟酸枣 | 计略 / MP / 谋士·策士登场 / 地形 / 伤害预测面板 | 学施放治疗+伤害计略；看预想伤害/命中 |
| 3 | 汜水关 | 据点占领 / 关隘地形 / ZOC 卡位 / 远程压制 / 天气(雾→远程) | 学攻坚与卡位；首个天气 |
| 4 | 虎牢关 | **单挑（三英战吕布）** / 客将 / 强敌应对 | 学单挑操作；客将仅本战 |
| 5 | 荥阳追击 | 伏击 / 撤退 / 护主 / 败战基调 + **印绶转职**（若有人达 Lv15）+ 整军商店首开 | 学转职与关间补给/买卖 |

- **阵型 / 状态异常深化 / 招募分支 / 升级成长率** 等留到第一章后段或第二章登场，节奏不挤。
- 每个「首次登场机制」配一个 `tutorial` 覆盖层步（见 §5）；触发后置 `storyFlags.taught_<机制>`，不重复弹。

## 5. 教程覆盖层编排（接 ui-ux §8 + content-pipeline 的 scenarioRunner `tutorial` 步）
- `{ type:'tutorial', id, anchor?, text, highlight?, dismiss:'click'|'action' }`：高亮目标 UI/格子 + 说明文，玩家操作或点击后关闭。
- 可在设置中关闭「新手提示」；已学过的（storyFlags.taught_*）不再触发。
- 教学点与 §4 表一一对应；首战密集、之后每战 1–2 个新点。
