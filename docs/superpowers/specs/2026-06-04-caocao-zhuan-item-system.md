# 《群雄逐鹿·孟德篇》道具系统 — 定稿

> 原创致敬作。沿用原版《三国志曹操传》的道具**体系结构与通用消耗品命名**（事实性设定）；
> 宝物用公有领域《三国演义》名物，**效果为本作自定**；不照搬任何商业游戏的数值表/文本。
> 状态：**已与 James 定稿**（3 槽；消耗品沿用原版名；果子/压级练果暂缓记待办；起步宝物清单见 §4）。

## 1. 装备：3 槽（武器 / 防具 / 饰品），按兵种限制
| 槽 | 内容 | 兵种限制 |
|---|---|---|
| 武器 | 剑(君主/盗贼/步兵)、枪·戟(骑兵)、弓(弓兵/弓骑兵)、双戟·锤·棍(武术家)、扇(策士/军师)、宝剑(道士/风水士)、投石·炮(炮车) | 按类型限定 |
| 防具 | **铠甲**=正规军(君主/步兵/弓兵/骑兵/弓骑兵)；**衣服/道服**=炮车及以下(武术家/盗贼/策士/道士/风水士) | 铠/衣分界=炮车 |
| 饰品 | 坐骑(马)、兵书、盾、宝玉、印 等（多为宝物） | 多数通用，部分限定 |

- 普通装备分**皮/铜/钢**（或布/皮/道服）三档，商店可买，武将加入自带（按等级配档）。
- `data/items.js`：Item = `{ id, name, slot:'weapon'|'armor'|'accessory', classes:[classId...], stats:{atk?,def?,int?,spd?,mov?,hp?,mp?}, special?:'effectId', tier, price }`。
