# 向僵尸开炮 BOMB ZOMBIE — 设计文档

> 竖屏阵地防守 + roguelite 升级构筑的爽快割草游戏，game-hub 收录。
> 参考「向僵尸开炮」。受众：成年向，硬核割草，追求数值膨胀的碾压爽感。
> 建立于 2026-06-20（brainstorming 产出）。

---

## 1. 概述与核心循环

底部一个角色 + 一道城墙，僵尸潮从屏幕上方向下推进，我方**全自动锁定开火**。击杀得经验，
升级时屏幕中央弹 **3 张卡片三选一**，拿加成滚雪球。守住城墙清完全部波次（Boss 关击败 Boss）即通关，
解锁下一关。打不过就回去**养成**（英雄/装备/永久强化）变强再来。

```
进入关卡 → 自动射击割草 → 击杀得经验 → 升级三选一(局内构筑) → 滚雪球
        → 守住城墙清完波次 / 打 Boss → 通关掉落(金币/装备/钻石) → 解锁下一关
        → (打不过) 局外养成: 升英雄/强化装备/点科技树/开宝箱 → 变强再战
```

**设计支柱（命门）**：操作全自动 → 游戏深度全部压在 **① 局内三选一构筑的协同深度 + ② 局外养成的成长感
+ ③ 割草数值反馈的爽快感** 三件事上。这三件做不好，养成系统再全也救不回来 → 因此分阶段先验证战斗。

**六个已锁定的设计维度**：
| 维度 | 决策 |
|---|---|
| 受众定位 | 成年向 · 硬核爽快割草 · 数值膨胀爽点 · 养成可做深 · 可有挑战 |
| 操作模式 | 角色**不走位**；平时**全自动锁定开火**，玩家只在升级三选一 + 择时放主动技能时决策 |
| 进度结构 | **章节闯关推图**：一关一场景，固定波次目标 + 章末 Boss，通关解锁下一关 |
| 养成深度 | **重养成**：英雄 + 装备/芯片 + 永久强化（跨局保留），分阶段落地 |
| 题材风格 | **经典僵尸末日**，成年向，废土/遮体围城；跟现有《成都保卫战》三国塔防错开 |
| 获取方式 | **通关掉落 + 金币商店 + 宝箱抽取**（单机无氪，钻石开箱抽英雄碎片/装备，纯爽点） |

## 2. 核心玩法（战斗 + 构筑 + 技能）

### 2.1 战场布局（竖屏纵向）
- 竖屏画布，自适应 iPad / 手机 / 桌面（竖屏为主，横屏加边或信箱处理）。
- **底部**：玩家角色（射手 / 炮台），固定在底部一带、**不走位**。
- 角色前方一道**城墙**（HP 条）= 最后防线。
- **上方**：僵尸从顶部多条"通道/列"持续向下推进。
- 僵尸走到城墙 → 啃墙扣城墙 HP；**城墙 HP 归零 = 本关失败**。

### 2.2 自动射击（全自动锁定）
- 角色自动锁定目标持续开火。默认锁**最近**；卡片可改成锁**最强 / 最密集**。
- 子弹数值维度：伤害 / 射速 / 弹数(多重) / 穿透 / 暴击率·暴击伤害 / 溅射范围 / 弹道类型(直线·扇形·追踪)。
- 最终数值 = **基础武器属性 × 局内卡片加成 × 局外养成加成**（三层叠加）。

### 2.3 敌人与波次（割草核心）
- **海量普通僵尸**（低血、成群）撑割草爽点。
- 变种（阶段 1 取 5~8 种）：
  - 快速僵尸（高速、低血）
  - 坦克僵尸（高血、慢）
  - 爆炸僵尸（死亡溅射伤害城墙/范围）
  - 护盾僵尸（正面减伤，需穿透/绕后）
  - 远程吐酸僵尸（远距离扣城墙）
  - 召唤者（持续召唤小僵尸）
- **波次（wave）**：每关由若干波组成，密度 / 血量 / 种类递增；章末 Boss 关。
- 数值随波次和章节**指数膨胀**，玩家靠构筑 + 养成对抗 → 制造"碾压感"。

### 2.4 局内构筑：经验 → 升级 → 三选一（每关独立，关结束重置）
- 击杀得经验，攒满 → **升级时暂停**，屏幕中央弹 3 张卡片，三选一。
- 卡池分类：
  - **武器强化**：+伤害 / +射速 / +多重弹 / +穿透 / +暴击率·暴击伤害 / +溅射范围
  - **元素特效**：燃烧(DoT) / 冰冻(减速) / 闪电(连锁) / 毒(叠层) / 击退
  - **防御**：城墙 +HP / 城墙回血 / 护盾 / 减伤
  - **经济·构筑**：+经验获取 / +金币 / 刷新卡 / 提升稀有度
- 卡片有**稀有度**（白/蓝/紫/金）：高稀有效果更强或质变。
- **进化卡**：部分卡叠满后可"进化"成质变效果（吸血鬼幸存者式协同）→ 制造 build 高潮。
- **每关一次独立 roguelite run**：局内等级与卡片在关结束重置；跨局成长靠局外养成保留。

### 2.5 主动技能（玩家唯一实时主动操作）
- 角色带 1~2 个主动技能（局外解锁/选择），有 CD：
  核弹清场 / 冰冻领域 / 炮火覆盖 / 召唤炮台 / 盾墙 等。
- 玩家点按钮 / 按键**择时释放** → 自动战斗里唯一需要判断时机的"操作翻盘"爽点。

### 2.6 数值反馈（爽点灵魂）
- 海量伤害飘字（暴击放大变色）、击杀血肉粒子/爆炸、连杀计数、屏幕震动、
  经验条/升级闪光、卡片登场仪式感。
- 数值越滚越大（几十 → 几千 → 几万伤害），强化碾压感。

## 3. 章节结构 + Boss

### 3.1 章节 / 关卡结构
- **章节制**：第 1 章「城郊废土」→ 第 2 章「沦陷都市」→ 第 3 章「地铁深渊」……
  每章 N 关 + 1 关章末 Boss。
- 每关 = 一段**固定波次脚本**（种类/密度/节奏经过设计），目标 = 守住城墙清完全部波次
  （Boss 关 = 击败 Boss）。
- 通关解锁下一关 + 结算掉落（金币 / 装备 / 材料 / 钻石）。
- 难度 + 数值随关卡膨胀，"打不过 → 回去养成 → 变强再来"。
- 关卡**数据驱动**（参考 tower-defender 的 campaign 数据表），方便扩量和平衡。

### 3.2 Boss 设计
- 章末大型 Boss：独立 HP 条 + 阶段转换 + 特殊机制——
  召唤小怪潮 / 范围地面攻击（逼玩家用主动技能）/ 弱点窗口 / 狂暴阶段。
- 每章高潮，集中考验玩家的构筑深度 + 养成强度。

## 4. 重养成系统（完整愿景蓝图 — 阶段 2 起落地）

### 4.1 英雄系统
- 多个可选英雄，各有不同**基础属性 + 专属被动 + 专属主动技能**：
  - 机枪手（高射速低伤）· 炮兵（高爆溅射）· 狙击手（高暴击穿透）·
    工程师（召唤炮台流）· 法师（元素叠层流）
- 英雄可用金币/碎片**升级**，提升基础面板；不同英雄改变 build 走向 → 重玩动机。

### 4.2 装备系统（"局外武器+加成"层）
- **主武器**：决定基础射击方式与数值（不同枪/炮，换武器=换手感）。
- **装备件/芯片**：护甲 · 瞄准镜 · 弹匣 · 引擎核心等，提供属性词条
  （攻击 / 射速 / 暴击 / 城墙 / 经验…）。
- 品质分级 白 → 绿 → 蓝 → 紫 → 橙，可消耗材料**强化升级**。

### 4.3 永久强化树（科技树）
- 金币消耗的全局属性树（攻击 / 血 / 经验 / 金币 / 暴击 等几条线），**所有英雄共享**，
  是金币的稳定出口。

### 4.4 获取方式（已定：通关掉落 + 金币商店 + 宝箱）
- 通关攒**钻石** → 开**宝箱**抽英雄碎片/装备（单机无氪、纯开箱爽点）。
- **金币商店**买强化、材料、永久强化树。
- 单机存档，无真实付费。

### 4.5 资源
- **金币**（养成主货币）· **钻石**（开宝箱）· **英雄碎片** · **装备材料**。

## 5. 分阶段交付计划（路线 A：战斗优先）

> 每阶段都有**客观门禁 + 可实玩中间态**（符合 large-builds-checkpoint-driven 原则）。

### 阶段 1 — 核心战斗可玩（首个检查点，本次主攻）
- 竖屏战场 + 城墙 + 自动锁定射击 + **1 个默认英雄/武器**。
- 波次系统 + **5~8 种僵尸** + **第 1 章约 8~10 关 + 1 个章末 Boss**。
- 局内经验/升级/三选一卡池（**约 24~30 张卡 + 几个进化**）+ **1~2 个主动技能**。
- 完整数值反馈（飘字/爆炸/震屏）+ 菜单/选关/暂停/结算 overlay + localStorage 进度。
- **门禁**：第 1 章可实玩通关 · 单测绿 · 浏览器/iPad 冒烟过 · 主观"好玩"验收。

### 阶段 2 — 养成闭环
- 英雄系统（3~5 英雄）+ 装备/芯片 + 永久强化树 + 金币/钻石/掉落/宝箱 + 养成 UI。
- 打通"掉落 → 强化 → 变强 → 推图"闭环。
- **门禁**：养成 loop 端到端可玩 · 数值平衡初校 · 测试绿。

### 阶段 3 — 内容扩展 + 打磨
- 第 2~3 章 + 更多僵尸/Boss/卡/英雄/装备。
- 平衡（模拟器）+ 图鉴/成就（可选，复用 tower-defender 成就经验）+ 音效/BGM/美术打磨。

## 6. 技术架构（沿用 game-hub 既有模式）

- **目录**：`games/bomb-zombie/` → `index.html` + `style.css` + `src/`(ES modules) +
  `tests/` + `README.md`；最后在 `js/games.js` 注册卡片。
- **渲染**：Canvas 2D；静态背景**离屏烘焙**（参考 tower-defender）。
- **模块草案**：
  - 核心：`main.js`(引导/主循环) · `game.js`(状态机) · `config.js`(数值表) ·
    `render.js` · `input.js`(键鼠/触屏/手柄) · `audio.js`
  - 实体：`entities/` → `hero.js` · `enemy.js` · `bullet.js` · `wall.js` · `boss.js`
  - 系统：`spawn.js`(波次) · `cards.js`(卡池+三选一) · `skills.js`(主动技能) · `levels.js`(关卡脚本)
  - meta（阶段 2 起）：`meta/` → `heroes.js` · `equipment.js` · `upgrades.js` ·
    `economy.js` · `save.js`
  - UI：overlay 模块（菜单/选关/暂停/结算/养成）
- **存档**：localStorage，进度 + 养成数据，独立**版本化 key**（参考 tower-defender 存档做法）。
- **全端**：触屏（点按放技能/点卡片）+ 键鼠 + 手柄；竖屏自适应。

## 7. 测试策略

- **纯逻辑单测**（node:test）：伤害结算 · 卡片叠加/进化 · 波次生成 · 掉落/经济 ·
  存档读写 · 升级曲线。
- **平衡模拟器**（仿 tower-defender 的 `sim-economy`）：模拟整局验证可通关性 + 数值膨胀曲线。
- **浏览器/iPad 冒烟**（host-side puppeteer，参考 boom-worms smoke 设置）。
- **检查点门禁**：每阶段测试绿 + 冒烟过 + 可实玩中间态。

## 9. 范围边界（YAGNI）

- **无**真实付费 / 联网 / 账号系统 —— 纯单机 localStorage。
- 阶段 1 **不做** 英雄/装备/养成 UI（先放 1 个默认英雄占位），先验证战斗与构筑。
- 抽卡=单机宝箱，仅消耗局内攒的钻石，**非**真实抽卡氪金系统。
- 不追求海量章节，先把第 1 章做精；内容横向扩展放阶段 3。
