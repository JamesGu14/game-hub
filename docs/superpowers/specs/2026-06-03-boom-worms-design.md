# 炮炮虫 BOOM WORMS — 设计文档 (Design Spec)

- **日期 / Date**: 2026-06-03
- **状态 / Status**: Approved (brainstorming 完成，待 implementation plan)
- **类型**: 新游戏 — 类《百战天虫》(Worms) 回合制炮战
- **目录**: `games/boom-worms/`
- **受众**: 7 岁一年级男孩，具备基本键鼠 + PS 手柄操作能力

---

## 1. 概述 / Overview

复刻一款类《百战天虫》的 2D 回合制炮战游戏，做成纯浏览器 Web 应用，接入 game-hub 导航页。
两队圆滚滚的小虫子在**可破坏地形**上轮流用各种武器互相轰炸，把对方虫子全部消灭（或打进水里）即获胜。
面向 7 岁儿童做了系统性简化：回合制无反应压力、不设硬性倒计时、风力默认关、无坠落伤害、操作不超过 4 个常用键、可爱非血腥美术。

### 目标 / Goals
- 还原百战天虫的核心乐趣：回合制策略 + 抛物线瞄准 + 地形破坏 + 把对手打飞/打进水里。
- 一个 7 岁孩子能独立上手：单人闯关打 AI。
- 能和爸爸/小伙伴沙发对战：双人同机轮流。
- 6 关主题战役，由易到难，有通关成就感。
- 键鼠与手柄都顺手（设备自适应操作）。

### 非目标 / Non-Goals (YAGNI)
- ❌ 网络多人 / 联机对战。
- ❌ 复杂武器库（80+ 武器、载具、武器合成）。
- ❌ 引信秒数手动调节、忍者绳荡绳、传送、建桥等高级工具（v1 不做，留作后续）。
- ❌ 程序化随机地图生成（v1 用手工参数化地形即可）。
- ❌ 自定义队伍/皮肤/墓碑等元数据系统。
- ❌ 触屏为主的交互（鼠标 = 指针事件，触屏可顺带能玩，但不作为 v1 重点）。

## 2. 技术与项目约定 / Tech & Conventions

- 纯 **Vanilla JS + ES Modules + Canvas 2D**，**无构建步骤**（与 `jungle-blitz` / `pixel-quest` 一致）。
- `config.js` 为纯数据，可被 `node:test` 直接 import（无 DOM 依赖）。
- 逻辑与渲染分离：纯逻辑模块（弹道、地形挖坑、伤害、AI 瞄准、胜负判定）可在 node 下单测。
- 中英双语标题、键盘 + 手柄、面向孩子（沿用 hub 风格）。
- 完成后在 `js/games.js` 注册卡片元数据，接入导航页。

## 3. 核心循环与回合状态机 / Game State Machine

主状态：`MENU → LEVEL_INTRO → TURN_ACTIVE → FIRING → PROJECTILE → RESOLVE → TURN_END → (循环) → LEVEL_CLEAR | GAME_OVER → WIN`

- **TURN_ACTIVE**：当前队某只虫子可移动 / 瞄准。**无硬性回合倒计时**（7 岁友好）。
- **FIRING**：蓄力中（按住）→ 松开发射。
- **PROJECTILE**：炮弹飞行，相机跟随。
- **RESOLVE**：结算爆炸伤害、击退、落水、死亡动画；可能掉宝箱。
- **TURN_END**：炮弹与所有虫子静止约 1 秒后，自动切换到下一队的下一只存活虫子（无 retreat 撤退时间，简化）。
- 一方虫子全灭 → 单人：`LEVEL_CLEAR`（解锁下一关）或 `GAME_OVER`（重玩本关）；双人：宣布胜方。
- 通关第 6 关 → `WIN`。

### 每队虫子数
- 默认**每队 3 只**。
- BOSS 关（彩虹山）敌方可 +1 只（4 只）以提升难度。

## 4. 可破坏地形系统 / Destructible Terrain（技术核心）

参照研究结论：**前景可破坏掩码 + 背景图**两层。
- 用一个离屏 `<canvas>`（地形层）保存地形：**alpha 通道即固体掩码**（不透明=固体，透明=空气）。
- **碰撞采样**：读取某像素 alpha 是否 > 阈值判断固体（虫子脚下/身体、炮弹命中）。
- **挖坑**：爆炸时在地形层用 `globalCompositeOperation='destination-out'` 清除一个圆 → 形成弹坑；坑沿可加焦边。
- **渲染**：每帧把地形层贴到主 canvas；主题色填充 + 顶部草皮/糖霜等装饰条。
- **生成**：每关按 `levels.js` 参数手工塑形（若干圆/blob + 轻噪声起伏 + 平台 + 洞穴），绘入地形层；底部留水位线。可固定布局，保证可玩与公平（宽平台、缓坡、可躲的大石）。
- 可测性：地形可用小尺寸布尔/掩码数组建模做单测（挖坑后掩码、碰撞采样）。

## 5. 虫子实体与物理 / Worm & Physics

- **Worm**：`{ team, x, y, vx, vy, hp(100), facing, alive, onGround }`。
- **移动**：左右走（速度受限），单段跳。受重力，与地形掩码碰撞（脚下采样找地面，身体两侧防穿墙）。
- **击退**：受爆炸冲量被打飞（夸张弹开），落地/静止后结算。
- **落水**：y 超过水位线 → 该虫子**出局**（水花特效，非血腥）。
- **坠落伤害**：**关闭**（仅落水出局），降低挫败感。
- 头顶绘制大号血条 + 队伍色（你方暖色 / 对手蓝色）+ 当前行动虫子高亮箭头。

## 6. 武器与炮弹 / Weapons & Projectiles

| 武器 | 类型 | 伤害(满) | 爆炸半径 | 弹药(每局) | 说明 |
|---|---|---|---|---|---|
| 🚀 火箭筒 Bazooka | 抛物线弹 | ~45 | ~45px | ∞ | 受重力(及风,若开)，撞击即爆 |
| 💣 手雷 Grenade | 抛掷+弹跳 | ~40 | ~42px | ∞ | 3 秒引信，地形弹跳 |
| 🧨 炸药 Dynamite | 原地放置 | ~60 | ~60px | 2~3 | 仅放在身边，~4 秒后大爆炸 |
| 🔫 霰弹枪 Shotgun | 瞬中(hitscan) | ~25/发 | 小坑 | 2~3 | 2 发，短程，强击退，挖地形 |
| 👊 飞拳 Fire Punch | 近身 | ~30 | — | 2~3 | 向上击飞，**不伤自己**(安全) |
| ✈️ 空袭 Air Strike | 选区天降 | 5×~25 | 多点 | 仅宝箱 | 光标选目标，数枚炸弹落下 |
| 🐑 圣手雷 Holy H.G. | 抛掷+大爆 | ~90 | 大 | 仅宝箱 | 致敬经典，超大威力惊喜 |

- **炮弹模拟** (`projectile.js`)：欧拉积分（重力、可选风力）、地形/虫子碰撞、引信计时、弹跳衰减、爆炸伤害随距中心距离线性衰减并附带击退冲量。
- **宝箱**：回合间按概率在地形上掉落，分**武器箱**（随机给一把特殊武器若干发，或空袭/圣手雷）与**血箱**（+30 HP）。虫子走到/被推到宝箱即拾取。

## 7. 瞄准与输入 / Aiming & Input（设备自适应）

| 动作 | 键鼠 | PS 手柄 |
|---|---|---|
| 走动 | ← → | 左摇杆 / 十字键 左右 |
| 跳 | ↑ 或 Z | ✕ |
| 瞄准 | 移动鼠标 = 准星指向（指哪打哪）；或 ↑↓ 微调角度 | 右摇杆 / 十字键 上下 调角度 |
| 蓄力发射 | 按住鼠标左键 / 空格 → 松开 | 按住 □（或 R2）→ 松开 |
| 换武器 | 底部武器栏点选 / Q E 循环 | L1 R1 循环 |
| 暂停 | Esc | Options |

- **设备自适应**：检测最近一次输入设备——动鼠标→准星跟随鼠标方向；用键盘/手柄→进入角度增减模式。两种可无缝切换。
- **蓄力条**：屏幕醒目位置的大蓄力条，随按住时间增长到满后封顶；配蓄力音效（音调/响度随力度上升），让孩子不盯屏也能感知。
- **风力指示**（开启时）：屏幕底部清晰风向箭头 + 强度。

## 8. 敌方 AI / AI（单人模式）

敌方回合流程：
1. **选目标**：综合最近距离 / 最低血量挑一个我方虫子。
2. **解算瞄准**：对火箭筒/手雷反解抛物线（已知起点、目标、重力、可选风），求一组可行的角度 + 力度；命中受地形阻挡时尝试调整或换走位。
3. **难度误差**：对解出的角度/力度加随机扰动——第 1 关误差大（常打偏），逐关收窄，彩虹山 BOSS 关接近精准。
4. **走位**：偶尔先朝有利位置移动再开火。
- 弹道解算器是纯函数，**单测**：给定场景验证落点落在目标爆炸半径内（难度=0 误差时必中），并验证各难度误差落在设定区间。

## 9. 双人同机 / Two-Player Hotseat

- 菜单选「单人闯关 / 双人对战」。
- 双人：两队轮流，使用同一套输入（同一键盘或同一手柄轮流操作），无 AI。
- 复用同一回合状态机，几乎零额外成本。双人可选地图主题，单局定胜负。

## 10. 关卡与主题 / Levels & Themes

6 关主题战役（已确认美术方向），由易到难：

| 关 | 主题 | 难度要点 |
|---|---|---|
| 1 | 🌱 绿草训练场 | 教学，AI 最弱，地形简单宽阔 |
| 2 | 🍭 糖果乐园 | AI 略强，引入更多平台 |
| 3 | 🏖️ 阳光海滩 | 海水更宽，落水风险高 |
| 4 | 🌳 神秘丛林 | 多平台 + 洞穴，地形复杂 |
| 5 | ☁️ 云端天空 | 浮空云岛，掉下/落水易出局 |
| 6 | 🌈 彩虹山决战 (BOSS) | AI 最准，敌方 +1 只 |

每关参数（地形布局、出生点、敌方数量、AI 难度、是否有风、宝箱频率）集中在 `levels.js` / `config.js`。

## 11. 规则默认值汇总 / Rule Defaults（均可调）

- **风力**：默认 **关**（全关卡）；菜单有「开启风力」开关，开后有清晰风向指示。
- **落水**：掉水 = 该虫出局（水花特效）。
- **坠落伤害**：**关**。
- **回合计时**：无硬性倒计时。
- **虫子血量**：100 HP。
- **每队虫子**：3 只（BOSS 关敌方 4 只）。

---

## 12. UI / HUD / 音效 / 存档

- **HUD**：当前队/虫子提示、所选武器与剩余弹药、蓄力条、风向（若开）、各虫子头顶血条、回合提示横幅。
- **Overlay 面板**（沿用 jungle-blitz 结构）：开始菜单（单人/双人 + 风力开关 + 最高进度）、暂停、关卡通过、失败重来、全通关胜利。
- **音效**（WebAudio，程序合成，无需音频资源）：发射、爆炸、蓄力、落水、拾宝箱、胜负；右上角静音按钮 + M 键。
- **存档**：通关进度（最远关卡）存 `localStorage`，沿用其它游戏的 `STORAGE_KEY` 命名模式（如 `boom-worms-progress`）。

## 13. 美术方向 / Art Direction

- 卡通圆滚滚小虫：大眼睛、咧嘴笑、戴帽子区分队伍；你方暖色、对手蓝色；被打飞时夸张弹开，落水可爱水花。
- 明亮饱和的主题配色（绿/糖果粉/沙黄/丛林绿/天蓝/彩虹），CSS 渐变 + 简单形状 + emoji 装饰，**无需外部图片资源**（与 hub 其它游戏一致）。

## 15. 测试策略 / Testing

`node:test`（与 jungle-blitz 一致）覆盖纯逻辑：
- 弹道积分（重力/风）落点正确。
- 地形挖坑后掩码与碰撞采样正确。
- 爆炸伤害随距离衰减、落水即出局。
- AI 瞄准解算（0 误差必中目标爆炸半径；各难度误差在区间内）。
- 回合切换 / 跳过死亡虫子 / 胜负判定。

渲染、输入、手柄等交互层用浏览器手动验证（webapp-testing / Playwright 可选）。
