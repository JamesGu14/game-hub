# 像素冒险 · PIXEL QUEST — 设计文档 (Design Spec)

**日期:** 2026-05-31
**类型:** 经典横版闯关（Mario 风格平台跳跃），2D，从左到右闯关，最后城堡救出公主。
**受众:** 7 岁儿童（具备基本键鼠 + PS 手柄操作能力）。
**定位:** 接入现有 `game-hub`，作为第 4 款游戏，遵循 `breakout` 的技术栈与约定。

---

## 1. 技术栈与项目约定（沿用 breakout）

- 纯 **Vanilla ES Modules + Canvas 2D**，**无构建步骤**（直接 `<script type="module">`）。
- 固定逻辑坐标系（FIELD），渲染时等比缩放 + 信箱黑边铺满画布，逻辑分辨率无关。
- 全中文 UI（zh-CN）。
- 输入：键盘 + 鼠标/触屏 + PS/Xbox 手柄统一抽象，每帧 `poll()` 读手柄。
- 音效：Web Audio 合成，无音频素材文件；可静音；首次手势后创建 AudioContext。
- 美术：**精细像素风**，全部用 canvas 绘制到离屏画布缓存（已在 brainstorm 定稿），金币用 🪙 emoji。**无图片素材**。
- 进度/最高分用 `localStorage`。
- 顶部「← HUB」返回链接、右上角静音按钮。
- 最后在 `js/games.js` 注册卡片接入导航页。

目录：`games/pixel-quest/`

---

## 2. 美术（已定稿）

精细像素风，原创绘制（不使用任天堂素材）：
- **主角**：Q 版可爱比例 —— 红帽（白圆徽章）+ 蓝背带裤 + 白手套 + 棕鞋 + 大眼睛高光 + 红脸蛋 + 小胡子。形态：`small` / `big`(变大) / `fire`(火力，帽衣偏白红)。
- **敌人**：蘑菇怪（矮胖、怒眉）、刺猬龟（绿壳黄边，可踩成壳）。尺寸参照原版：不大于主角。
- **公主**：皇冠 + 粉裙；**城堡**：石墙城垛拱门塔楼旗。
- **元素**：问号砖（经典干净形态）、砖块、水管、终点旗杆、🪙 emoji 金币、🍄 蘑菇 / 🌻火之花 / ⭐星星 道具。
- 角色加简单动画帧：行走（双腿交替）、跳跃姿势、变身闪烁。

所有绘制函数从 brainstorm 的 `pixel-hd3.html` 移植到 `src/sprites.js`，绘到离屏 canvas 缓存，渲染时 `imageSmoothingEnabled=false` 放大。

## 3. 关卡（1 个世界，4 关）

主题递进，最后救公主：
1. **1-1 草地关**：入门关，平缓地面、问号砖、少量蘑菇怪、水管、几个小坑、隐藏金币。教学：跑/跳/踩怪/顶砖。
2. **1-2 地下关**：暗色砖洞穴，更多平台跳跃、金币串、刺猬龟、稍多坑。
3. **1-3 空中/水管关**：移动平台 + 消失平台为主，大空隙（可助跑跨过），高处隐藏奖励，星星道具。
4. **1-4 城堡关**：石砖城堡，狭窄通道、跳跃陷阱、敌人组合，终点为**城堡 + 公主**，救出公主 → 通关 Win。

每关末尾有**终点旗杆**（除城堡关，城堡关末尾直接进城堡救公主）。旗杆按抓握高度给奖励分。

### 关卡数据格式（`levels.js`，ASCII 瓦片图，参照 breakout 的 ASCII 思路）
逐行字符串数组，**自顶向下**（最后一行贴地）。瓦片图例：

| 字符 | 含义 |
|---|---|
| (空格) | 空气 / 天空 |
| `#` | 地面（顶部带草，实心） |
| `X` | 实心石块 |
| `B` | 可破坏砖块（big 主角可顶碎；含隐藏金币变体 `b`） |
| `?` | 问号砖（出金币） |
| `M` | 问号砖（出道具：小则蘑菇，大则火之花） |
| `o` | 漂浮金币 |
| `[` `]` | 水管左/右（成对，2 宽，可站立） |
| `=` | 漂浮固定平台（实心可站） |
| `~` | 移动平台生成点（水平/垂直，元数据指定） |
| `g` | 蘑菇怪生成点 |
| `k` | 刺猬龟生成点 |
| `*` | 星星砖（顶出星星） |
| `F` | 终点旗杆 |
| `A` | 城堡（仅 1-4，含公主） |
| `@` | 主角出生点 |
| `c` | 中点检查点（旗标） |

每关附元数据对象：`{ id:'1-1', name:'草地', theme:'overworld'|'underground'|'sky'|'castle', rows:[...], platforms:[{x,y,axis,range,speed}], time:300 }`。

> 坑（掉落致死）= 地图底部该列没有地面，主角掉出画面底即坠落。

## 4. 玩法机制

- **移动**：左右加速度 + 摩擦；`run` 键提高最大速度。地面/空中操控。
- **跳跃**：可变高度（按住跳更高）；加 **coyote time**（离开平台后短时间仍可跳）+ **jump buffer**（落地前按跳记忆）——对儿童更宽容。
- **踩怪**：从上方落下 → 蘑菇怪被踩扁消灭；刺猬龟被踩 → 缩壳静止 → 再踩/碰可踢出，壳滑行撞死其它怪（也会反伤主角）。
- **道具**：
  - 🍄 蘑菇：`small→big`（变高，可顶碎砖块）。
  - 🌻 火之花：`big→fire`，按 `run/fire` 键发射火球（弹跳前进，打死敌人）。
  - ⭐ 星星：短时无敌 + 加速，碰怪秒杀，主角闪烁。
- **受伤模型**：`fire/big` 受击 → 降一级（fire→big→small）+ 短暂无敌闪烁；`small` 受击 或 坠坑 → 损 1 命。
- **金币**：触碰/顶问号砖获得；**100 金币 +1 命**；计分。
- **问号砖/砖块**：从下方顶 → 问号砖弹出金币/道具；`big` 主角顶碎 `B` 砖（small 只能顶动）。
- **终点旗杆**：触碰 → 滑下 → 走入城堡 → 本关结算（旗高奖励 + 剩余时间奖励）。
- **移动/消失平台**：主要在 1-3；玩家可站立并随之移动。
- **隐藏奖励**：部分 `b` 砖含金币；高处隐藏平台/金币。

## 5. 难度（两档，开始菜单选，沿用 breakout 的 easy/classic 思路）

| | 简单·儿童版（默认） | 经典 |
|---|---|---|
| 生命 | 5 | 3 |
| 检查点 | 每关中点 `c`，死亡从检查点复活（保留关卡进度） | 无，死亡回本关开头 |
| 敌人速度 | 较慢 | 标准 |
| coyote/jump-buffer | 更宽松 | 标准 |
| 道具掉率 | 更高 | 标准 |
| 坠坑 | 损命但宽容（检查点） | 损命，回开头 |

用完所有命 → Game Over（可重选难度 / 重玩 / 返回 HUB）。通关 1-4 救出公主 → Win。

## 6. 操作映射

| 动作 | 键盘 | PS/Xbox 手柄 | 触屏 |
|---|---|---|---|
| 移动 | ← → / A D | 左摇杆 / 十字键 | 左下角 ◀▶ 按钮 |
| 跳 | 空格 / ↑ / W | ✕ (按钮0) | 右下角 ⤴ 按钮 |
| 跑 / 火球 | Shift / J | □ (按钮2) | 右下角 ● 按钮 |
| 暂停 | Esc / P | Start (9) | 暂停图标 |
| 确认（菜单） | Enter / 空格 | ✕ | 点击 |
| 返回 | Backspace | ○ (按钮1) | — |
| 静音 | M | — | 右上角 🔊 |

**跑键非必须**：关卡设计成不按跑也能通关；助跑只是让大空隙更轻松、火力形态发射火球。

## 7. 模块架构（`games/pixel-quest/`）

```
index.html      画布 + HTML 叠层(menu/story/pause/levelclear/gameover/win) + ←HUB + 静音 + 触屏按钮
style.css       全屏画布、叠层面板、儿童友好大按钮、触屏控制
src/
  config.js     物理常量、MODES(easy/classic)、瓦片图例、TILE 尺寸、计分、STORAGE_KEY、主题配色
  sprites.js    像素美术：所有角色/元素绘到离屏 canvas 缓存（移植自 pixel-hd3）；提供动画帧
  audio.js      Web Audio 音效 + 简单循环背景旋律（按主题），可静音
  input.js      键盘+手柄+触屏统一：连续 moveX(-1..1) + held.run/jump + 离散动作(jump/pause/confirm/back/mute/fire)
  levels.js     4 关 ASCII 图 + 元数据 + 移动平台参数；解析为瓦片网格 + 实体生成列表
  physics.js    AABB 与瓦片网格碰撞解析（先 X 后 Y）、重力积分、辅助函数
  entities.js   Player / Goomba / Koopa / Shell / Coin / Powerup / Fireball / MovingPlatform 类与 update
  game.js       状态机、关卡加载、相机、命/分/检查点、胜负
  render.js     相机变换、视差背景(按主题)、瓦片绘制、实体绘制、HUD、信箱缩放
  main.js       构建模块、RAF 主循环(dt 钳制)、连接 input 与叠层、状态同步
```

模块边界：`sprites/audio/input/config/levels` 相互独立；`physics`被`entities`用；`entities`+`levels`喂给`game`；`render`读`game`状态+`sprites`绘制；`main`只做装配与循环。

---

## 8. 状态机（game.state）

`menu`（选难度）→ `story`（一句话剧情：公主被抓，出发！可跳过）→ `ready`（关卡开场提示）→ `playing` ↔ `paused` → `levelclear`（结算，下一关）→ 循环至 1-4 → 救公主 → `win`；任意 `playing` 死亡且无命 → `gameover`。

相机：水平跟随主角（含死区），钳制到关卡左右边界；竖直基本固定/必要时跟随。

---

## 9. 构建顺序

1. `config.js` 2. `sprites.js` 3. `audio.js` 4. `input.js` 5. `levels.js`（4 关）
6. `physics.js` 7. `entities.js` 8. `game.js` 9. `render.js`
10. `index.html` + `style.css` 11. `main.js` 12. 注册 `js/games.js`
13. 浏览器验证（语法检查 + 实机跑 4 关 + 手柄/键盘）+ 多维代码评审，迭代修复。

---

## 10. 验收标准

- 4 关均可从头玩到尾，最后 1-4 能救出公主进入 Win。
- 键盘与 PS 手柄都能流畅操作（跑/跳/踩怪/火球/暂停/返回 HUB）。
- 蘑菇变大、火球、星星、踩怪、顶砖、金币、移动平台、检查点、两档难度均生效。
- 7 岁可上手：简单档宽容、不易卡死、失败不挫败。
- 60fps 流畅；画面为定稿的精细像素风；接入导航页卡片可正常启动。
- 无控制台报错；返回 HUB 正常。
