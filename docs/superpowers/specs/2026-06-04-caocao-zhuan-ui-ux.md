## 0. 设计原则（贯穿全稿）

1. **一屏一焦点**：等距 3D 沙盘是主舞台；DOM 覆盖层只承载信息与决策，绝不抢戏。沿用 `.hud` 的「层 `pointer-events:none`、子元素 `auto`」约定，让点击默认落到 canvas（选格/选将）。
2. **国风一致**：所有新界面复用 `style.css` 的 `--gold #d4af37 / --gold-soft / --vermilion #7a1f1f / --ink #161d2e / --parchment #efe3c4`、`.panel` / `.big-btn` / `.game-title` / `ccz-fade` 动画与卷轴/朱金边风格；每个 UI 模块用「一次性注入 `<style id="ccz-*-styles">`」的既有模式扩样式，不污染全局。
3. **预测优先（SRPG 手感）**：出手前可见结果（移动范围、攻击威胁、伤害预测面板——引用 `ui/forecast.js`）。
4. **可达性内建**：字号档、高对比、色盲友好、键鼠+手柄三态对等，从一开始设计进 IA，不做补丁。
5. **数据单一事实源**：所有中文标签（兵种/计略/状态/天气/道具）从 `data/*` 取，UI 不另维护文案表（沿用 `hud.classLabel`/`skillLabel`/`STATUS_META` 现状，新增标签也走 data）。

## 1. 信息架构（IA）与场景流

### 1.1 顶层场景流（与 `main.js` 现有「菜单→章节→整军→战斗→剧情→结算」一致）

```
标题(title)
  └─ 开始征途 ─▶ 章节地图(chapterMap) ─▶ 整军(intermission) ─▶ 战前剧情(dialogue/scenario)
       │                                                          │
       │                                                          ▼
       └─ 继续 ─▶ 读档(saveLoad) ─────────────────────────▶ 战斗(battle HUD)
                                                                  │ 战中触发：剧情/单挑(duelView)
                                                                  ▼
                                                            胜负结算(result) ─▶ 整军/下一战
```

- **新增节点**：`chapterMap`（章节地图，§3）、`codex`（图鉴/列传，§7）、`settings`（设置，§9）、`tutorial`（教程覆盖，§8）。后三者从标题与暂停均可进。
- **状态机契约**：现有界面均已是「调用 → 返回 Promise / 回调」模式（`menus.title({onStart,onContinue})`、`intermission.run(ctx)→Promise`、`scenarioRunner.run`、`duelView.run→Promise`）。新节点遵循同样的「`run(ctx)→Promise<结果>`」契约，便于 `main.js` 顺序编排。

## 2. 战斗 HUD（核心界面）

主舞台是 3D 沙盘；HUD 是贴边的「框」。所有部件挂在 `#hud`（`ui/hud.js`）。

### 2.1 HUD 部件布局（屏幕分区）

```
┌─────────────────────────────────────────────────────────┐
│ [←HUB]          ☀ 晴 · 第 3 回合 · 我军(4/5)        [🔊]│  ← 顶部状态条（天气/回合/阵营行动）
│                                                          │
│                                                  ┌──────┐│
│                                                  │ 小地图││  ← 右上：战场小地图(§5)
│                                                  └──────┘│
│              （等距 3D 沙盘 = 主舞台）                    │
│                                                          │
│ ┌────────────┐                          ┌──────────────┐│
│ │ 单位信息卡  │                          │ 行动菜单/     ││  ← 左下信息卡(现 ccz-unit-card)
│ │ (悬停/选中) │                          │ 计略子菜单    ││     右下行动菜单(现 ccz-action-menu)
│ └────────────┘                          └──────────────┘│
└─────────────────────────────────────────────────────────┘
```

- **左下 单位信息卡** = 现 `showUnit(unit)`，保留。**改造点**：属性栏从当前 `攻/防/智/速/移` 迁移到设计语料的五维 **攻/精/防/爆/士 + 移**（与职业体系 §0 对齐；这是已记录的迁移项）。HP 条（`ccz-hp-fill` low/mid/high 三色）保留。增加：天气/地形对该单位的当前修正小标（如「林：防+2 回避+」），状态徽章沿用 `STATUS_META`。
- **右下 行动菜单** = 现 `actionMenu(actions)`，保留浮动定位与「Esc/右键/点外取消→`cancel`」手势。菜单项顺序约定：`移动 / 攻击 / 计略 / 道具 / 待机`（道具为新增项，见 §2.4）。
- **顶部状态条（新）**：天气图标+名（悬停展开影响说明，数据来自 `battle/weather.js` 的 `weatherMods`）、`第N回合`、当前行动阵营与「已动/总数」（如 我军 4/5）。挂 `#hud` 顶部居中，避开 `#back-to-hub`/`#btn-mute`（左右各 14px 已占）。
- **右上 小地图（新）**：见 §5。

### 2.2 选将 → 移动 → 攻击 的高亮链（与职业体系 §1 一致）

选中我方单位时，**同屏三色高亮**（由 `render3d` 在地块上绘制，HUD 仅显示图例）：
- **蓝**＝可移动格（`pathfind` 移动范围）；
- **红**＝移动后按 `attackShape`（cross/star/diamond/area）可攻击到的威胁范围；
- 选定落点后，再高亮**该点的可攻目标**（描边/脚环）。

进入攻击/计略目标模式时（`main.js` 的 `pendingMode='attack'|'skill'`）：悬停/选目标即弹 **伤害预测浮层**（`ui/forecast.js`，`#forecast` 层）——内容、双向预测、颜色编码见 `…damage-preview.md`，本稿不复述。

### 2.3 计略子菜单（复用 `hud.skillMenuItems`）

- 选「计略」→ 用现有 `skillMenuItems(skillIds, usesLeft, hasTarget)` 生成项：标签含剩余次数 `（N）`、无目标 `（无目标）`、耗尽 `（次数耗尽）` 并 `disabled`；每项带 `desc`（`skillBrief` 程序化生成：元素/范围/威力/附加状态/射程）。
- **天气联动（新）**：当计略受当前天气限制时，附标与禁用——`require` 未满足 → `（需 雨/雪）`、`blockedIn` 命中 → `（雨天火势难成）`、`powerMod` 影响 → desc 末尾追加「晴·威力↑」等小标（取自天气稿 §3 的 `weather` 字段）。`disabled` 判定并入现有 `disabled = 次数<=0 || 无目标 || 天气不可用`。
- 选定计略 → 进目标格选择 → AOE 用 `area` footprint 高亮覆盖格 → 逐目标预测浮层。

### 2.4 道具行动（新增菜单项，对接道具系统）

- 行动菜单加「道具」：打开消耗品子菜单（同 `actionMenu` 浮层样式），列该单位/全军可用消耗品（道具系统 §2：恢复用豆/米/桃、神秘水/酒、解毒药、膏药、止咳药、兴奋剂）。
- 每项显示 名称 + 效果简述 + 持有数；选中→选目标（自疗/对友军/解状态）→ 确认。**印绶**不在战斗中用（仅整军，§6.2）。
- 用毕消耗并刷新；与移动/攻击的「一回合一行动」规则一致（道具是否消耗整个行动由 battle 决定，UI 只呈现 `actions()` 给出的可用项）。

### 2.5 回合/相位演出（复用 `turnBanner`）

- 我军回合/敌军回合/第 N 回合 用现有 `turnBanner(text, ms)`（金字朱影、`ccz-fade`）。
- 天气切换（计略/剧情触发 `setWeather`）：顶部状态条图标切换 + 一次短横幅（如「东风骤起」），`render3d` 同步粒子（雨/雪/雾）。

## 4. 整军界面（intermission，扩展现有）

现有 `intermission.run(ctx)` 已实现：名册列表（立绘+等级+兵种+HP）、详情（立绘+名号+属性网格+已学计略+随身装备+军备库）、装备/卸下、兵书研习、存档、出征。**保留全部**，按设计语料扩展：

### 4.1 属性五维化
详情属性网格从现 `HP/攻/防/智/速/移` 迁移到 **HP/攻/精/防/爆/士/移**（与职业体系 §0、伤害公式一致），装备加成 `(+n)` 标注保留。`computeStats` 同步五维口径。

### 4.2 三槽装备（道具系统 §1）
当前是「随身物列表」自由装备。改为 **武器/防具/饰品 三槽**：详情区显示三个固定槽位（空槽=「—，点击装备」），点槽 → 军备库筛选**该槽 + 该兵种可装**的道具（按 `Item.slot` + `classes` 限制，违规项灰显并注「此兵种不可用」）。卸下回军备库。属性合并沿用 `computeStats` 叠加（hp/atk/精/def/爆/士）。

### 4.3 印绶转职（道具系统 §3 / 职业体系 §3）
- 详情区加「转职」按钮：仅当 `level>=15`（→中级）或 `level>=30`（→高级/可选中）且军备库有 **印绶(seal)** 时可点。
- 点击 → 弹「转职」确认层（同整军内嵌弹层 `ccz-int-scroll`，复用 `openSavePicker` 的居中弹层模式）：显示「`轻骑兵 → 重骑兵`」、五维跃升预览、解锁的更高阶计略列表、消耗 1 枚印绶 + 满血满蓝提示；确认 → 写 `entry.classTier`/`classId`、消耗印绶、toast。
- 君主线（群雄→英雄→霸王）随剧情成长，**不在整军用印绶**（按钮注「主公循义而进，无须印绶」并禁用）。

### 4.4 消耗品补给
军备库中消耗品（豆/米/桃/水/酒/解毒…）在整军可对武将使用（回 HP/MP、解状态、关间预备），与战斗中道具行动同一目录、不同入口。

### 4.5 计略一览
「已习计略」每项点开看完整说明（元素/范围/威力/MP 消耗/射程/天气限制），并标「下一级（Lv.X）习得：XX」给成长预期（数据来自职业体系各系技能表）。

> 兵书研习（现 `learnBook`）保留为「计略书道具→习得」的补充路径。

## 5. 战场小地图（minimap，新部件）

- **位置**：HUD 右上角，固定小卡（`pointer-events:auto`，可点跳转视角）。约 160×120，可折叠（缩成图标）。
- **内容**：整张战场缩略——地形底色（路/草/林/山/水/城据点，取 `data/terrain.js` 颜色）、单位点（我军金、友军青、敌军朱、未行动加亮环）、据点/出口标记、当前镜头视野框、当前选中单位脉动点。
- **交互**：点小地图某处 → `render3d/camera` 平移到该处（等距锁定不变，仅 pan）；键鼠拖拽地图同样平移。
- **实现**：`ui/minimap.js` 用一个 `<canvas>`（轻量 2D，不引 three）订阅 `eventBus` 的单位/回合/天气变更重绘；或并入 `hud.js`。数据从 `gameState` + `battleController` 取格子与单位。
- **无障碍**：小到看不清时提供「展开大地图」键（默认 `Tab` 切换，见 §10）。

## 6. 对话/剧情演出（复用 dialogue + scenarioRunner）

## 7. 武将列传 / 图鉴 / 宝物图鉴（codex，新界面）

- **数据**：`GENERALS[id]`（appearance/base/growth/classId/skills）+ 新增 `lore` 字段（原创小传，放 `data/generals.js` 或单独 `data/lore.js`）。解锁状态来自 `storyFlags`/遭遇记录。

## 8. 新手教程 / 操作提示（tutorial，新覆盖层）

第一章前两战（陈留教学/酸枣计略）按 master design 的教学目标分步引导；机制随关解锁。

- **形式**：`#tutorial` 层（z 700）——**聚光遮罩**（暗化全屏、镂空高亮目标部件/格子）+ 国风提示气泡（朱金边小卡）+「知道了/下一步」。不阻断真实操作（让玩家边学边做）。
- **触发**：`scenarioRunner` 可发 `tutorial` step（`{tip:'move', anchor:'unit'|'menu:attack'|'cell:x,y'}`），或 `eventBus` 首次进入某模式时触发对应提示，看过即写 `storyFlags.tut_*` 不再弹。
- **教学清单（与 master §4.2 教学目标对齐）**：选将/移动范围/确认落点 → 攻击与相克与**伤害预测** → 计略与 MP 与**天气限制** → 地形（防/回避/移动消耗）→ 道具 → 单挑过场 → 整军/转职/装备 → 存读档。
- **常驻操作提示**：HUD 角落「?」按钮随时调出**当前可用操作小抄**（按输入设备显示对应键位/按钮，§10）。
- **可重看**：设置里「重看教程」清除 `tut_*` 标记。

## 9. 设置（settings，新界面）

从标题、暂停均可进。渲染进 `#menus`（`.panel`）。落地到 `game.state.settings`（master 存档格式已含 `{muted, difficulty, textSpeed}`，本稿扩展）。

| 分组 | 项 | 取值 | 落点 |
|---|---|---|---|
| 音频 | 主音量 / 音乐 / 音效 | 0–100 滑杆 + 静音开关（与 `#btn-mute`/M 键同步）| `settings.volume{master,bgm,sfx}` + `muted` |
| 难度 | 难度 | 轻松/标准/困难（影响敌 AI 与数值，master §3.10）| `settings.difficulty` |
| 文本 | 文本速度 | 慢/正常/快/立即 | `settings.textSpeed`（dialogue 已读）|
| 文本 | 自动播放 / 已读跳过 | 开关 | `settings.autoPlay` / `settings.skipRead` |
| 操作 | 输入提示设备 | 自动/键鼠/手柄 | `settings.inputHint` |
| 无障碍 | 见 §10 | — | `settings.a11y{...}` |
| 数据 | 重看教程 / 清空存档（二次确认）| 按钮 | 清 `tut_*` / localStorage |

- 设置即时生效并 `game.save`（或写 settings 专属 key，独立于战局存档）。滑杆/开关用国风样式（金描边、朱填充）。

## 10. 输入：键鼠 + 手柄（对等）

三态对等。当前代码已有：对白点击/Enter/Space 推进；行动菜单 Esc/右键/点外取消；静音 M（标题注）。统一为下表，新增手柄映射。

| 操作 | 键鼠 | 手柄 |
|---|---|---|
| 选格/选将/确认 | 左键点击 | A |
| 取消/返回/关菜单 | 右键 / Esc | B |
| 移动光标（沙盘格）| 鼠标悬停 / 方向键 | 左摇杆 / 十字键 |
| 平移镜头 | 边缘/拖拽/WASD | 右摇杆 |
| 打开行动菜单 | 选将后自动弹 | A（选将后）|
| 切目标（攻击/计略/预测）| 悬停 / Tab 循环 | LB/RB 循环 |
| 计略/道具子菜单 | 菜单内点选 | A 选、B 退 |
| 对白推进 / 快进 | 点击/Enter/Space / 按住 Ctrl | A / 按住 RT |
| 小地图大图切换 | Tab | 触摸板键 / Select |
| 暂停菜单 | Esc（非目标态）/ P | Start |
| 静音 | M | — |
| 结束本方回合 | 按钮 / Enter（无选中时）| Start 长按 / 菜单 |

- **手柄实现**：`ui/input.js`（新，可选）统一抽象「光标移动/确认/取消/循环目标」事件经 `eventBus` 派发，HUD/main 订阅，与键鼠走同一路径（菜单焦点用「当前高亮项 + A 确认」）。手柄为 master 标注的「后续」项，**v1 可 phase**——但 IA 与事件抽象先留好，避免后期返工。
- **焦点可见**：所有可交互元素有清晰键盘/手柄焦点环（金色 2px outline），不仅靠 hover。

## 11. 无障碍（a11y，内建）

落到 `settings.a11y`，全局 CSS 变量/类切换实现（不改逻辑）。

- **字号档**：`fontScale` 小/中/大（`html { font-size }` 基准缩放；各界面用 `clamp()`/`em` 已大量支持，受益面广）。对白/信息卡/菜单全跟随。
- **高对比**：`a11y.highContrast` → 加 `body.hc` 类：提高 parchment/ink 对比、加粗描边、降低半透明遮罩的透明度、弱化金色光晕，保证文字对比≥WCAG AA。
- **色盲友好**：阵营/状态/高亮不**仅**靠颜色——
  - 移动蓝/威胁红高亮叠**纹理或描边样式**（蓝=实线网、红=斜线网），并在图例标文字；
  - 单位阵营除颜色外加**形状标记**（我=圆环、友=方框、敌=三角）于脚环与小地图；
  - 状态徽章已是「图标+文字+回合数」（`STATUS_META`），保留这一多通道编码；
  - HP 条 low/mid/high 除三色外加数值与可选「斜纹=危险」纹理。
- **可读性**：打字机可关（textSpeed=立即）；对白支持加大行高档；关键提示同时给文字+图标。
- **减少动效**：`a11y.reduceMotion` → 关闭横幅/淡入/单挑冲刺缓动（尊重 `prefers-reduced-motion`，单挑改为瞬切+文字战报）。
- **不依赖声音**：所有 SFX 关键反馈（命中/失败/无法行动）都有视觉对应（飘字/抖动/toast）。

## 12. 视觉语言（国风，与 style.css 一致）

- **色**：金 `--gold` 主强调（标题/边框/可选高亮）、朱 `--vermilion` 行动/危险/敌方、墨夜 `--ink` 背景、宣纸 `--parchment` 正文。新部件一律取这些变量，不引新基色（高对比模式除外）。
- **形**：圆角卡（14–18px）、金描边（2–3px）、卷轴头（`scroll-knob`）、`box-shadow` 厚重立体 + `inset` 金线（沿用 `.panel`/`ccz-unit-card`）。按钮统一「朱金立体 + `:active` 下沉」（`.big-btn`/`ccz-action-btn`/`ccz-foot-btn` 同款手感）。
- **字**：`STKaiti/KaiTi/PingFang SC` 楷书优先（已在 body），标题大字加朱影金面。
- **动效**：`ccz-fade` 统一入场；横幅金字朱影；单挑黑边 letterbox 电影感。减少动效模式下可全关。
- **图标**：优先 Unicode/程序化绘制（如天气 ☀☔❄🌫️、状态 ☠✦⛓⚔🛡）——与现有 `STATUS_META` 一致，**不引入第三方图标字体/图片**（离线、无版权风险）。

## 14. 范围与分期（phaseable）
