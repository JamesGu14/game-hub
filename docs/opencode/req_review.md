# 《成都保卫战》需求设计评审报告

## 一、总体评价

这份设计文档（298行）整体框架完整，核心循环清晰，三国题材与塔防机制的绑定有亮点。但**从可执行开发的角度看，仍有多处关键参数缺失、机制定义模糊、系统间存在隐性矛盾**。以下按严重性分层列出。

---

## 二、需求清晰度分析（按章节）

### 1. 核心玩法循环 — 较清晰，但边界未定义

| 问题 | 严重度 | 说明 |
|---|---|---|
| 波次间金钱是否继承 | 🔴高 | 文档说"起始金钱200→320"，但没说明波次之间金钱是**清零**还是**累积**。从"击杀掉金"推断是累积，但必须明确。 |
| 提前出兵奖励上限 | 🟡中 | "剩余秒数×2"——倒计时30秒时奖励60金，几乎够造一座黄忠。这是否会导致经济滚雪球？（见逻辑漏洞#5） |
| 快进对计时器的影响 | 🟡中 | 2×快进是否影响**所有**计时（备战倒计时、debuff持续时间、子弹飞行）？还是仅敌人和塔的CD？ |

### 2. 地图与路径 — waypoint 系统严重不足

| 问题 | 严重度 | 说明 |
|---|---|---|
| waypoint 数据结构未定义 | 🔴高 | "道路是一串waypoint"——waypoint包含什么字段？`(x,y)`？是否有`arrivalAction`（停顿、转向）？转弯时敌人朝向如何插值？ |
| 将位数量/分布 | 🔴高 | "分布于道路两侧"——每关有几个将位？是否有射程无法覆盖的死角？将位间距是否标准化？ |
| 飞兵"直线"的精确定义 | 🟡中 | "敌营→成都直线"——是从敌营中心到成都中心的直线？飞兵高度如何处理？防空将打飞兵时射程按直线距离还是平面距离？ |

### 3. 胜负条件 — 判定精度缺失

| 问题 | 严重度 | 说明 |
|---|---|---|
| "冲到中心"的判定 | 🔴高 | waypoint终点就是成都中心？敌人碰撞体积多大？成都占地2×2格，敌人到达边界即扣血还是到达中心？ |
| 敌营攻陷后的影响 | 🟡中 | 敌营标记"攻陷"后是否仅视觉变化？是否停止出兵（已出完的当然不会出）？多营场景中一座攻陷是否降低整体压力？ |
| 多路同时进攻的平衡 | 🟡中 | 8座敌营同时出兵时，成都四面受敌。是否有机制确保每路都有将位可布防？否则某些路天然漏怪。 |

### 4. 将塔系统 — **最大缺口：缺少射程和攻速定义**

| 问题 | 严重度 | 说明 |
|---|---|---|
| **射程完全缺失** | 🔴🔴致命 | 6将表格中**没有射程列**。塔防游戏射程是核心参数——黄忠速射但射程短？关羽水攻范围多大？诸葛亮火烧是单体还是范围？这些决定了布防策略。 |
| **攻击速度/冷却缺失** | 🔴🔴致命 | "单体速射""高单体""射速很慢"都是描述性词汇，无法转化为代码。每座塔的**攻击间隔（秒）**是多少？升级后是否减少？ |
| 升级属性提升 | 🔴高 | "L2≈造价×1.0"是**花费**，不是属性提升。升级后伤害/射速/射程分别提升多少%？是固定倍率还是曲线？ |
| 招牌技触发机制 | 🔴高 | 文档§15自己标注"招牌技触发是被动概率还是冷却"待定。这是**核心战斗机制**，必须在开发前敲定。 |
| 灼烧蔓延规则 | 🟡中 | 诸葛亮"火攻灼烧·蔓延"——蔓延的触发条件？敌人死于灼烧后火焰跳向附近敌人？最大蔓延次数？蔓延范围？ |
| 马超穿透机制 | 🟡中 | "直线穿透多目标"——是子弹穿过第一个继续打后面？一次攻击最多穿透几个？穿透后伤害是否衰减？ |
| 拆除返还60%的基数 | 🟡中 | 是**建造成本**的60%，还是**总投入（含升级）**的60%？ |

### 5. 敌军系统 — BOSS行为模糊，状态叠加未定义

| 问题 | 严重度 | 说明 |
|---|---|---|
| BOSS是否有特殊AI | 🔴高 | "名将BOSS统帅"——BOSS只是**血厚的普通 waypoint 跟随者**，还是有特殊行为（召唤小兵、攻击将塔、释放技能）？如果只是血多，"统帅"一词有误导性。 |
| 方士治疗参数 | 🔴高 | "持续治疗周围友军"——范围多大？治疗频率？治疗量？多个方士治疗同一目标是否叠加？ |
| 状态效果叠加规则 | 🔴高 | 敌人可同时拥有减速+灼烧+定身+被治疗。这些状态是否独立计时？定身期间减速效果是否暂停？ |
| 藤甲抗性计算 | 🟡中 | "抗物理50%；怕火+50%"——诸葛火攻打藤甲是 `150%` 伤害？物理攻击是 `50%`？火焰伤害类型是否独立于物理/谋略？ |
| 飞兵的实际威胁 | 🟡中 | 飞兵速度"中"，轻骑速度"快"。但飞兵走直线，道路是弯曲的，**飞兵实际到达时间可能比轻骑更短**。这是否是有意设计？ |
| 出兵密度与间隔 | 🟡中 | "每波敌军从各敌营涌出"——一座敌营一波出几个？出怪间隔？是否一次性涌出还是分批？ |

## 三、逻辑漏洞与矛盾

### 🔴 漏洞 #1：马超"直线穿透"与弯曲道路的物理矛盾

> 马超招牌技"西凉突阵：直线穿透多目标+击退"。但道路是**刻意弯曲的**，敌人在弯道上不会排成严格直线。这意味着马超的穿透在弯道上几乎无法命中多个目标，实际效果远低于设计预期。

**建议**：要么将穿透改为"扇形/锥形范围"，要么在关卡设计中确保马超将位前有直线路段。

### 🔴 漏洞 #2：赵云"仅地" vs 飞兵+BOSS混合波次

> 赵云专克BOSS（高单体），但"仅地"。如果某波BOSS带飞兵护卫同时来袭，赵云对飞兵完全无能为力。而飞兵直扑成都，防空将（黄忠/关羽/诸葛亮）必须分火力处理飞兵，可能导致BOSS无人处理。

**建议**：明确飞兵是否总是与地走敌人分波出现，或给赵云一个"可对空但效率极低"的降级模式。

### 🔴 漏洞 #3：关羽"谋略(无视护甲)"的标注冗余

> 表格说"关羽谋略×藤甲=有效"，但藤甲特性只是"抗物理50%"。谋略伤害本就不受物理抗性影响，对所有敌人都一样有效。**特别标注对藤甲有效是逻辑冗余**，除非藤甲还有"抗谋略"属性未写明。

### 🔴 漏洞 #4：提前出兵的经济正反馈循环

> 提前出兵→获得大量金币→立刻建更多塔→本波更轻松→下波更容易提前出兵。如果奖励 = 剩余秒×2 不设上限，前期每波提前出兵可能让玩家在第3波就拥有远超设计预期的经济。

**建议**：设置提前出兵奖励上限（如每波最多30金），或改为固定小额奖励+波次清怪奖励。

### 🔴 漏洞 #5：方士"优先点杀"策略的可行性存疑

> 文档推荐"最弱/最后模式专点方士"。但如果方士HP=50（不是最弱）、位于敌群中间（不是最后），目标模式无法锁定它。且方士"持续治疗周围友军"，即使被集火，也可能被其他方士互奶。

**建议**：明确方士的AI行为（是否刻意走在队伍中间？），或给方士一个高仇恨值（让"最强"模式也能优先打它）。

### 🟡 漏洞 #6：黄忠"暴击必中"在塔防语境下含义模糊

> 塔防游戏中"命中"概念通常不存在（子弹是碰撞检测或范围判定）。"必中"是指子弹追踪？还是敌人无法闪避？如果游戏本无闪避机制，"必中"就是无意义属性。

**建议**：改为"必定暴击"或"无视护甲/闪避"等明确机制。

## 五、建议

### 立即补齐（开发阻塞项）

1. **补全6将数值表**：增加"射程（格数）"、"攻击间隔（秒）"、"子弹速度"三列。
2. **定义招牌技触发**：建议统一为"冷却制"（如L3后每X秒自动触发一次），比概率制更可控。
3. **定义波次表JSON Schema**：至少包含 `waveId, campId, enemyType, count, spawnInterval, pathId`。
4. **定义waypoint格式**：建议 `[{x, y, waitTime, speedMultiplier}]`，支持路径点停留和变速。

### 设计调整建议

1. **马超穿透改为"锥形AOE"**：解决弯曲道路无法命中的问题。
2. **提前出兵奖励设上限**：如每波最多奖励 = 备战时间 × 1（而非×2），防止经济失控。
3. **赵云增加降级对空**：可对空但伤害-50%，避免飞兵波次完全依赖其他三将。
4. **方士增加"高仇恨"属性**：让部分目标模式（如"最强"）优先锁定它，使"优先点杀"策略真正可行。

### 美术风险缓解

1. **M1先做色块占位**：用彩色方块+文字标签替代sprite，验证玩法后再批量生成美术。
2. **统一AI生成Prompt模板**：为6将定义统一的画风Prompt前缀，确保出图一致性。

---

**总结**：这份设计文档在**概念层**非常扎实（题材包装、核心循环、克制关系），但在**执行层**有大量关键参数和机制规则缺失。**建议先补充P0级待决事项，产出一份"可开发版本"的设计文档，再进入M1开发。**
